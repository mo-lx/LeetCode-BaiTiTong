### 1.2 必须理解的本专题约定

- **位运算三大性质**：`a ^ a = 0`（成对抵消）、`a ^ 0 = a`（保留原值）、`a ^ b ^ a = b`（交换律结合律）
- **技巧触发靠"信号"**：看到"成对出现"→ 异或；"出现次数 > n/2"→ 摩尔投票；"三色分类"→ 荷兰国旗；"值域映射成环"→ Floyd 判圈
- **数组当链表**：`nums[i]` 的值表示下一个下标（值域在 [1, n] 时），可构造隐式链表判环

## 二、本质理解（专题核心思想）

技巧题 = **信号识别题**：题目里的某个特征，直接指向一个固定技巧。

```
成对出现、找唯一 → 位运算（异或）
出现次数 > n/2 → 摩尔投票
只含 0/1/2 三色 → 荷兰国旗（三指针）
字典序下一个排列 → 三步法
值在 [1,n] 中找重复 → 数组当链表 + Floyd 判圈
```

每个技巧都对应一个**数学性质**，理解性质才能举一反三。

## 三、核心模板技巧

### 模板 1：位运算 —— 找只出现一次的数

**一句话原理：** 异或满足"成对抵消"，把所有数异或一遍，成对的都归零，剩下的就是唯一落单的数。

**使用场景：** 数组中找只出现一次（其余均成对出现）的数。

**模板代码：**
```python
def single_number(nums):
    res = 0
    for num in nums:
        res ^= num          # 成对抵消，剩下落单的
    return res
```

**复杂度：** O(n) / O(1)。

**易错点：** 依赖"其余恰好出现两次"；异或结果初值 0。

**关联题目：**
- [[02-Wiki/题目详解/136-只出现一次的数字]]

### 模板 2：摩尔投票 —— 多数元素

**一句话原理：** 候选与计数器：相同 +1、不同 -1、归零换候选。因为众数数量超过一半，最终留下的必是众数。

**使用场景：** 出现次数严格 > n/2 的多数元素。

**模板代码：**
```python
def majority_element(nums):
    candidate = nums[0]
    count = 1
    for num in nums[1:]:
        if count == 0:
            candidate = num
            count = 1
        elif num == candidate:
            count += 1
        else:
            count -= 1
    return candidate
```

**为什么对：** 众数与其他所有数"一换一"抵消后，由于众数超过一半，必然剩下众数。

**复杂度：** O(n) / O(1)。

**易错点：** 需先确认众数确实 > n/2（题目保证时不必二次验证）。

**关联题目：**
- [[02-Wiki/题目详解/169-多数元素]]

### 模板 3：荷兰国旗 —— 三指针（颜色分类）

**一句话原理：** 三个指针把数组分成 0 区、处理区、2 区。0 与 p0 交换、2 与 p2 交换；`cur` 遇到 0/1 前进，遇到 2 交换后**不前进**（换来的值未处理）。

**使用场景：** 只含 0/1/2（三色）原地排序。

**模板代码：**
```python
def sort_colors(nums):
    p0 = 0                # 0 区右边界
    cur = 0               # 当前处理位置
    p2 = len(nums) - 1    # 2 区左边界
    while cur <= p2:
        if nums[cur] == 0:
            nums[p0], nums[cur] = nums[cur], nums[p0]
            p0 += 1
            cur += 1       # 换来的必是 0 或 1，可直接前进
        elif nums[cur] == 2:
            nums[p2], nums[cur] = nums[cur], nums[p2]
            p2 -= 1
            # cur 不 +1：换过来的可能是 0，需重新处理
        else:              # nums[cur] == 1
            cur += 1
```

**复杂度：** O(n) / O(1)。

**易错点：** 与 2 交换后 `cur` 不 +1；与 0 交换后 `cur` +1。

**关联题目：**
- [[02-Wiki/题目详解/75-颜色分类]]

### 模板 4：下一个排列 —— 三步法

**一句话原理：** ① 从右往左找第一个升序对 `(i, i+1)`；② 从右往左找第一个比 `nums[i]` 大的元素交换；③ 翻转 `i+1` 之后使其升序。

**使用场景：** 字典序下一个排列；全排列的相邻生成。

**模板代码：**
```python
def next_permutation(nums):
    i = len(nums) - 2
    while i >= 0 and nums[i] >= nums[i + 1]:   # 1. 找第一个升序对
        i -= 1
    if i >= 0:
        j = len(nums) - 1
        while j >= 0 and nums[j] <= nums[i]:   # 2. 找第一个更大的
            j -= 1
        nums[i], nums[j] = nums[j], nums[i]    # 3. 交换
    left, right = i + 1, len(nums) - 1         # 4. 翻转后半段
    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1
```

**复杂度：** O(n) / O(1)。

**易错点：** 第一步找的是 `nums[i] < nums[i+1]` 的**最靠右**位置；整数组已降序时 i = -1，只翻转。

**关联题目：**
- [[02-Wiki/题目详解/31-下一个排列]]

### 模板 5：Floyd 判圈 —— 寻找重复数

**一句话原理：** 把数组当链表（`nums[i]` 是下一个下标），值域 `[1, n]` 保证有环；找环入口 = 找重复数。

**使用场景：** 值在 `[1, n]` 的 n+1 个元素中找重复数（不能改数组、O(1) 空间）。

**模板代码：**
```python
def find_duplicate(nums):
    slow = fast = nums[0]
    while True:                      # 阶段1：相遇
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break
    slow = nums[0]                   # 阶段2：找环入口
    while slow != fast:
        slow = nums[slow]
        fast = nums[fast]
    return slow
```

**复杂度：** O(n) / O(1)。

**易错点：** `fast = nums[nums[fast]]` 跳两步；与链表判环同构（见 [[02-Wiki/专题总结/04-链表]] 模板 6）。

**关联题目：**
- [[02-Wiki/题目详解/287-寻找重复数]]

## 四、模板选择决策（什么时候用哪个）

```
题目特征 → 技巧
├── 成对出现，找唯一落单 → 模板1 异或
├── 出现次数 > n/2 → 模板2 摩尔投票
├── 只含 0/1/2 三色，原地排序 → 模板3 荷兰国旗
├── 求字典序下一个排列 → 模板4 三步法
├── 值在 [1,n] 中找重复（不能改数组） → 模板5 Floyd 判圈
└── 都不是 → 回常规专题（哈希/排序/双指针）
```

## 五、易错点清单（专题级全局易错点）

1. **异或适用范围**：只在"其余恰好成对"时成立，出现三次的不行
2. **摩尔投票**：需要众数确实 > n/2；否则结果无意义
3. **荷兰国旗**：与 2 交换后 `cur` 不前进（换来的值未处理）
4. **下一个排列**：升序对必须是最靠右的；已降序时直接翻转
5. **Floyd 判圈**：数组值必须都在 `[1, n]` 才能当下标
6. **数组当链表**：不要修改原数组（否则破坏映射）
