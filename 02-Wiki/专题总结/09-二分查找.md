# 09 · 二分查找

> **来源：** labuladong 二分查找统一模板 + 代码随想录循环不变量  
> **核心价值：** 在有序空间中用 O(log n) 找到目标，每次排除一半数据；不只对数组二分，也对"答案值域"二分  
> **题量：** 6 题（Hot 100 二分查找）

## 一、前备知识（开始本专题前必须会什么）

### 1.1 Python 语法最小示例

| 知识点 | 最小示例 | 本专题用途 | 自检问题 |
|--------|----------|-----------|----------|
| 整除 | `mid = left + (right - left) // 2` | 防溢出取中 | 为什么不写 `(l+r)//2`？ |
| 模块 | `from bisect import bisect_left, bisect_right` | 内置二分 | `bisect_left` 返回什么？ |
| 条件判断 | `nums[mid] < target` | 收缩区间 | `<` 与 `<=` 的区别是什么？ |
| 旋转数组 | `nums[left] <= nums[mid]` | 判断哪半有序 | 旋转数组如何判断有序半区？ |

### 1.2 必须理解的本专题约定

- **使用二分的三个条件**：① 搜索空间有序（或单调）；② 可 O(1) 随机访问；③ 一次比较可排除一半
- **区间约定统一**：`[left, right]` 闭区间，`while left <= right`；收缩时 `mid ± 1`
- **`mid` 防溢出**：`mid = left + (right - left) // 2`
- **二分答案**：单调性不一定在"数组下标"上，也可能在"答案的值域"上（如最大值最小化）

1. `while left <= right` 和 `while left < right` 有何不同？
2. 标准二分为什么 `left = mid + 1`、`right = mid - 1`？
3. 左边界二分的收缩条件是什么？
4. 什么情况下要"对答案值域二分"？

## 二、本质理解（专题核心思想）

labuladong 的定位：

> **二分查找 = 在有序空间中暴力穷举的优化版。** 每次通过比较中间值，排除一半的搜索空间。

**关键：把"二分"理解为对"单调性质的分界点"的搜索，而不只是"找某个值"。** 左/右边界、旋转数组、二分答案本质都是"找单调性质第一次/最后一次成立的位置"。

## 三、核心模板技巧

### 模板 1：标准二分查找

**一句话原理：** 闭区间 `[left, right]`，`mid` 与 target 比较，排除一半。

**使用场景：** 在**有序无重复**数组中查精确值。

**模板代码：**
```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**复杂度：** O(log n) / O(1)。

**易错点：** `left <= right` 保证区间非空；`mid ± 1` 防止死循环。

**关联题目：** [[02-Wiki/题目详解/35-搜索插入位置]]（变体）

### 模板 2：寻找左侧边界（第一个 ≥ target）

**一句话原理：** 当 `nums[mid] >= target` 时收缩右边界，锁定最左的满足位置；结束时 `left` 即答案候选。

**使用场景：** 插入位置、重复元素的第一个位置、找下界。

**模板代码：**
```python
def left_bound(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1          # 收缩右边界，锁定左侧
    if left >= len(nums) or nums[left] != target:
        return -1
    return left
```

**复杂度：** O(log n) / O(1)。

**易错点：** 返回前要检查 `left` 越界与值是否存在；`else` 分支含 `==`。

**关联题目：**
- [[02-Wiki/题目详解/35-搜索插入位置]]
- [[02-Wiki/题目详解/34-在排序数组中查找元素首末位置]]（左边界 + 右边界）

### 模板 3：寻找右侧边界（最后一个 ≤ target）

**一句话原理：** 与左边界对称：`nums[mid] <= target` 时收缩左边界，锁定最右。

**使用场景：** 重复元素的最后一个位置、找上界。

**模板代码：**
```python
def right_bound(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] <= target:
            left = mid + 1           # 收缩左边界，锁定右侧
        else:
            right = mid - 1
    if right < 0 or nums[right] != target:
        return -1
    return right
```

**复杂度：** O(log n) / O(1)。

**易错点：** 返回前检查 `right` 越界；注意与左边界收缩方向的对称性。

**关联题目：**
- [[02-Wiki/题目详解/34-在排序数组中查找元素首末位置]]

### 模板 4：搜索旋转排序数组

**一句话原理：** 二分时先判断 `mid` 落在哪段有序区间（左半或右半），再判断 target 是否在该区间内，从而决定收缩方向。

**使用场景：** 旋转后的有序数组查值。

**模板代码：**
```python
def search_rotated(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        if nums[left] <= nums[mid]:          # 左半有序
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:                                # 右半有序
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
```

**复杂度：** O(log n) / O(1)。

**易错点：** 用 `nums[left] <= nums[mid]` 判断左半有序（含相等，处理长度为 2 的情况）；区间判断要含端点。

**关联题目：**
- [[02-Wiki/题目详解/33-搜索旋转排序数组]]

### 模板 5：寻找旋转排序数组最小值

**一句话原理：** 比较 `nums[mid]` 与 `nums[right]`：`mid` 处大于右侧 → 最小值在右半（`left = mid+1`）；否则最小值在左半含 mid（`right = mid`）。

**使用场景：** 无重复旋转数组找最小值；找旋转点。

**模板代码：**
```python
def find_min(nums):
    left, right = 0, len(nums) - 1
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] > nums[right]:      # 最小值在右半
            left = mid + 1
        else:                            # 最小值在左半（含 mid）
            right = mid
    return nums[left]
```

**复杂度：** O(log n) / O(1)。

**易错点：** 这里 `while left < right`（不是 `<=`），`right = mid` 保留 mid（因为 mid 可能就是最小）；`mid` 靠左取。

**关联题目：**
- [[02-Wiki/题目详解/153-寻找旋转排序数组中的最小值]]

### 模板 6：搜索二维矩阵 —— 一维化二分

**一句话原理：** 把 m×n 矩阵拉直成一维下标 `[0, m*n-1]`，`matrix[mid // n][mid % n]` 取元素，再标准二分。要求**整体**按行递增（每行首 > 前行尾）。

**使用场景：** 严格有序二维矩阵查值（整体有序，区别于 240 的行列独立有序）。

**模板代码：**
```python
def search_matrix(matrix, target):
    if not matrix or not matrix[0]:
        return False
    m, n = len(matrix), len(matrix[0])
    left, right = 0, m * n - 1
    while left <= right:
        mid = left + (right - left) // 2
        val = matrix[mid // n][mid % n]
        if val == target:
            return True
        elif val < target:
            left = mid + 1
        else:
            right = mid - 1
    return False
```

**复杂度：** O(log(m·n)) / O(1)。

**易错点：** 一维转二维 `mid // n`、`mid % n`；仅适用于"整体有序"矩阵。

**关联题目：**
- [[02-Wiki/题目详解/74-搜索二维矩阵]]

### 模板 7：两个正序数组的中位数 —— 分割线二分

**一句话原理：** 在**较短**数组上二分分割线 i，另一个分割线 `j = (m+n+1)//2 - i`；满足 `nums1_left <= nums2_right and nums2_left <= nums1_right` 即找到合法分割。

**使用场景：** 两有序数组的中位数 / 第 K 小（Hard，但思路通用）。

**模板代码：**
```python
def find_median_sorted_arrays(nums1, nums2):
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    m, n = len(nums1), len(nums2)
    left, right = 0, m
    while left <= right:
        i = (left + right) // 2                  # nums1 分割线
        j = (m + n + 1) // 2 - i                 # nums2 分割线
        nums1_left = nums1[i - 1] if i > 0 else float('-inf')
        nums1_right = nums1[i] if i < m else float('inf')
        nums2_left = nums2[j - 1] if j > 0 else float('-inf')
        nums2_right = nums2[j] if j < n else float('inf')
        if nums1_left <= nums2_right and nums2_left <= nums1_right:
            if (m + n) % 2 == 0:
                return (max(nums1_left, nums2_left) + min(nums1_right, nums2_right)) / 2
            else:
                return max(nums1_left, nums2_left)
        elif nums1_left > nums2_right:
            right = i - 1
        else:
            left = i + 1
```

**复杂度：** O(log min(m, n)) / O(1)。

**易错点：** 在短数组上二分（保证 j 不越界）；边界用 ±inf 处理；奇偶分割区分。

**关联题目：**
- [[02-Wiki/题目详解/4-寻找两个正序数组的中位数]]

### 模板 8：二分答案 —— 对值域二分

**一句话原理：** 当"答案"是某个数值（而非下标）且具有单调性时，对**答案值域**二分：`mid` 作为候选答案，用 `check(mid)` 判断可行性，不断逼近最优解。典型"最大值最小化 / 最小值最大化"。

**使用场景：** 吃香蕉速度、分割数组最大值、在 D 天内送达包裹等（Hot 100 无直接题，但面试高频）。

**模板代码：**
```python
def min_eating_speed(piles, h):
    def can_finish(speed):                  # check 函数：该速度能否完成
        return sum((p + speed - 1) // speed for p in piles) <= h

    left, right = 1, max(piles)             # 答案值域 [1, max]
    while left < right:
        mid = left + (right - left) // 2
        if can_finish(mid):
            right = mid                     # 可行 → 试试更小
        else:
            left = mid + 1                  # 不可行 → 需要更大
    return left
```

**复杂度：** O(n log R)（R 为值域大小）/ O(1)。

**易错点：** `check` 的单调性要先确认；`right = mid`（可行保留 mid）vs `left = mid + 1`（不可行排除）。

**关联题目：** 875 吃香蕉、410 分割数组最大值（延伸题，无详解文件）

### 模板 9：Python `bisect` 模块

**一句话原理：** 内置二分，`bisect_left` 返回第一个 ≥ x 的位置，`bisect_right` 返回第一个 > x 的位置。适合"有序数组插入/查找"的快速实现。

**模板代码：**
```python
from bisect import bisect_left, bisect_right, insort

a = [1, 3, 3, 5]
bisect_left(a, 3)    # → 1（第一个 ≥ 3 的下标）
bisect_right(a, 3)   # → 3（第一个 > 3 的下标）
insort(a, 4)         # 插入后保持有序
```

**复杂度：** O(log n) / O(1)。

**易错点：** `bisect_left` 与 `bisect_right` 在"有重复元素"时的返回值不同。

## 四、模板选择决策（什么时候用哪个）

```
二分题先问：二分的是下标还是答案？
├── 下标二分（数组有序/单调）
│   ├── 查精确值 → 模板1 标准二分
│   ├── 查第一个/最后一个位置 → 模板2/3 左右边界
│   ├── 旋转数组查值 → 模板4（判断有序半区）
│   ├── 旋转数组找最小 → 模板5
│   ├── 整体有序二维矩阵 → 模板6 一维化
│   └── 两有序数组中位数 → 模板7 分割线二分
└── 答案值域二分（答案有单调性）
    └── 最大值最小化/最小值最大化 → 模板8 二分答案
        ├── 先确认 check(mid) 单调
        └── 可行收缩 / 不可行扩大
```

## 五、易错点清单（专题级全局易错点）

1. **循环条件**：`left <= right`（闭区间）→ `mid ± 1`；`left < right`（开区间）→ `right = mid`。保持一致
2. **mid 防溢出**：`mid = left + (right - left) // 2`
3. **左/右边界收缩方向**：找左界 `>=` 时收缩 `right`；找右界 `<=` 时收缩 `left`
4. **旋转数组**：先判断 mid 在哪段有序区间，再判断 target 位置；`nums[left] <= nums[mid]` 处理长度 2
5. **二分答案**：`check` 的单调性是前提；`right = mid` 保留可行 mid，`left = mid + 1` 排除不可行
6. **边界越界**：左界返回前检查 `left >= len(nums)`；右界检查 `right < 0`；分割线用 ±inf
