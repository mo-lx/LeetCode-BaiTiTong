### 1.2 必须理解的本专题约定

- **哈希表本质 = 数组 + 哈希函数**：key → 数组下标，O(1) 查找/插入/删除
- **key 必须可哈希（不可变）**：`int/str/tuple` 可以，`list/dict/set` 不可以 → 需要时用 `tuple` 包一层
- **工具选型**：存在性 → `set`；键值映射 → `dict`；频次 → `Counter`；分组收集 → `defaultdict`
- **什么时候用哈希表**：需要"快速判断某个元素是否出现过"或"统计出现次数"时

## 二、本质理解（专题核心思想）

哈希表本质是**数组 + 哈希函数**：用哈希函数把 key 映射到数组索引，实现 O(1) 的查找、插入、删除。

**核心思想：空间换时间。** 用额外内存换取更快的查找。

**四大应用场景：**

| 场景 | 说明 | 典型题目 |
|------|------|----------|
| 查找 | 快速判断元素是否存在 | 1. 两数之和 |
| 去重 | 判断元素是否重复出现 | 128. 最长连续序列 |
| 计数 | 统计元素出现次数 | 49. 字母异位词分组 |
| 分组 | 按规则将元素归类 | 49 / 560 |

**本质套路：** 当你需要**快速查找某个元素是否出现过**，或**统计某个值的出现次数**时，考虑哈希表。

## 三、核心模板技巧

### 模板 1：两数之和 —— 边遍历边查

**一句话原理：** 遍历时把 `(值 → 索引)` 存入字典；对每个元素查"互补值是否已出现"即可 O(n)。边遍历边查保证不自匹配、且前值不被覆盖。

**使用场景：** 找两个元素满足某种关系（和/差/积）的经典"互补查找"。

**模板代码：**
```python
def two_sum(nums, target):
    seen = {}                       # 值 -> 索引
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i               # 先查后存，避免自匹配
    return []
```

**复杂度：** O(n) / O(n)。

**易错点：** **先查后存**——先存入再查会把当前元素自己算进去。

**关联题目：**
- [[02-Wiki/题目详解/1-两数之和]]

### 模板 2：字母异位词分组 —— 排序/计数作 key

**一句话原理：** 异位词排序后相同，或字符计数相同 → 用"排序后的字符串"或"计数元组"做分组 key。

**使用场景：** 按某种等价关系分组（字母异位词、频率相等元素）。

**模板代码：**
```python
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))        # 排序后的元组作为 key
        groups[key].append(s)
    return list(groups.values())
```

**优化（长字符串时更快）：**
```python
def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        count = [0] * 26
        for c in s:
            count[ord(c) - ord('a')] += 1
        groups[tuple(count)].append(s)   # 计数元组作 key
    return list(groups.values())
```

**复杂度：** O(n·k log k)（排序版）或 O(n·k)（计数版）/ O(n·k)。

**易错点：** key 必须可哈希（用 `tuple`，不能直接用 list）。

**关联题目：**
- [[02-Wiki/题目详解/49-字母异位词分组]]

### 模板 3：最长连续序列 —— 集合去重 + 找起点

**一句话原理：** 把数组放进集合，**只从"没有前驱"的元素**（`num-1 not in set`）开始向后扩展，保证每个元素只被访问一次 → O(n)。

**使用场景：** 求最长连续序列（O(n) 要求，不能排序）。

**模板代码：**
```python
def longest_consecutive(nums):
    nums_set = set(nums)
    longest = 0
    for num in nums_set:
        if num - 1 not in nums_set:      # 关键：只从序列起点开始
            current = num
            length = 1
            while current + 1 in nums_set:
                current += 1
                length += 1
            longest = max(longest, length)
    return longest
```

**为什么对：** 只有"起点"才触发扩展，每个连续段只被处理一次，总复杂度 O(n)。

**复杂度：** O(n) / O(n)。

**易错点：** 遍历集合而非原数组（去重）；起点判断 `num - 1 not in nums_set` 是核心优化。

**关联题目：**
- [[02-Wiki/题目详解/128-最长连续序列]]

### 模板 4：前缀和 + 哈希表 —— 和为 K 的子数组

**一句话原理：** 子数组 `[i,j]` 和为 k ⇔ `prefix[j+1] - prefix[i] = k`；用哈希表记录"之前出现过的前缀和次数"，边遍历边累计。

**使用场景：** 统计和为 k 的**连续**子数组个数；**数组含负数时不能用滑动窗口**，必须此法。

**模板代码：**
```python
from collections import defaultdict

def subarray_sum(nums, k):
    count = 0
    cur_sum = 0
    sum_count = defaultdict(int)
    sum_count[0] = 1                    # 空前缀和 = 0 出现 1 次
    for num in nums:
        cur_sum += num
        count += sum_count[cur_sum - k]  # 之前有多少个前缀和 cur_sum-k
        sum_count[cur_sum] += 1
    return count
```

**为什么对：** 每个和为 k 的子数组唯一对应一对 `(i, j)`，`sum_count[cur_sum - k]` 恰好统计可配对的 i 数量。

**复杂度：** O(n) / O(n)。

**易错点：** 初始化 `sum_count[0] = 1`；**必须先 count 后存**，否则把当前元素自己算进去。

**关联题目：**
- [[02-Wiki/题目详解/560-和为K的子数组]]（跨 [[02-Wiki/专题总结/03-数组与矩阵]]）

## 四、模板选择决策（什么时候用哪个）

```
题目特征 → 哈希表工具
├── 查互补/是否出现过 → 模板1 边遍历边查（dict/set）
├── 统计频次/分组 → 模板2 Counter / defaultdict 分组
├── 去重 + 找连续/序列 → 模板3 集合 + 找起点
├── 连续子数组和 → 模板4 前缀和 + 哈希计数
└── 需要排序吗？
    ├── 允许 O(n log n) → 也可以排序 + 双指针（见 02）
    └── 要求 O(n) → 必须哈希表
```

**哈希 vs 排序 vs 双指针：**
- 哈希表：O(n) 空间换时间，适合"查找/计数"
- 排序 + 双指针：O(1) 额外空间，但 O(n log n)，适合"需要有序性"的题（如三数之和）
- 滑动窗口：O(1) 空间 + O(n)，但要求窗口单调（含负数失效）

## 五、易错点清单（专题级全局易错点）

1. **Key 必须可哈希**：`list` 不能做 key，`tuple` 可以
2. **defaultdict vs dict**：计数/分组用 `defaultdict` 省去判空
3. **Counter.most_common(k)**：底层用堆，直接返回 Top K
4. **边遍历边查**：两数之和"先查后存"，避免自匹配
5. **前缀和顺序**：先 count 后存，`sum_count[0]=1` 不能少
6. **集合去重**：`set(nums)` 比 dict 去重更简洁；遍历集合而非原数组
7. **dict 最坏 O(n)**：Python 实现高度优化，最坏仅哈希冲突严重时
