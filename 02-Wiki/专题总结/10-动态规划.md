## 一、前备知识（开始本专题前必须会什么）

### 1.2 必须理解的本专题约定

- **DP 三特征**：最优子结构 / 重叠子问题 / 无后效性
- **方法论**：labuladong 四步法（base case → 状态 → 选择 → dp 含义）或代码随想录五部曲
- **两种实现**：自顶向下（记忆化递归，好思考）+ 自底向上（迭代，更高效）
- **dp[i] 的语义要写清楚**：是"以 i 结尾"还是"前 i 个"，直接决定转移方程

## 二、本质理解（专题核心思想）

labuladong 的精辟定义：

> **动态规划 = 穷举 + 记忆化**

**两个核心问题：**

| 问题 | 说明 | 解决方式 |
|------|------|----------|
| 如何穷举 | 不重不漏地遍历所有可能的解 | 状态转移方程 |
| 如何聪明地穷举 | 避免重复计算 | 备忘录（memo）/ DP 表 |

**DP 三特征：**

| 特征 | 说明 | 反例 |
|------|------|------|
| 最优子结构 | 子问题最优解能推导原问题最优解 | 走迷宫（需全局信息） |
| 重叠子问题 | 子问题被重复计算 | 斐波那契数列 |
| 无后效性 | 子问题解一旦确定不受后续影响 | 股票问题（需状态维度） |

**常见模型一览：** 线性 DP → 打家劫舍/背包 → 子序列 → 编辑距离 → 路径 DP → 区间 DP，模型选择见第四节决策表。

## 三、核心模板技巧

### 模板 1：方法论框架（两种实现）

**一句话原理：** 自顶向下"递归 + memo"天然贴合思考；自底向上"for 循环填表"更高效、可空间优化。

**使用场景：** 所有 DP 题的起手式。

**模板代码：**
```python
# 方式一：自顶向下（记忆化递归）
from functools import lru_cache

@lru_cache(None)
def dp(state):
    if "base case":
        return base_val
    # 做选择
    return max/min(选择1, 选择2, ...)

# 方式二：自底向上（迭代）
dp = [base_val] * (n + 1)
for i in range(1, n + 1):
    for choice in choices:
        dp[i] = max/min(dp[i], dp[i - choice] + cost)
return dp[n]
```

**复杂度：** 取决于状态数与转移成本。

**易错点：** `lru_cache(None)` 或 `lru_cache(maxsize=None)`；递归参数必须是可哈希的。

### 模板 2：线性 DP —— 爬楼梯 / 斐波那契

**一句话原理：** `dp[i] = dp[i-1] + dp[i-2]`，只依赖前两个状态，可滚动 O(1) 空间。

**使用场景：** 一维线性递推类。

**模板代码：**
```python
def climb_stairs(n):
    if n <= 2:
        return n
    a, b = 1, 2
    for _ in range(3, n + 1):
        a, b = b, a + b          # 滚动变量
    return b
```

**复杂度：** O(n) / O(1)。

**易错点：** base case 的 n=1/2 处理。

**关联题目：**
- [[02-Wiki/题目详解/70-爬楼梯]]
- [[02-Wiki/题目详解/118-杨辉三角]]（组合数递推）

### 模板 3：打家劫舍 —— 选 / 不选

**一句话原理：** 对每家两种选择：偷（`dp[i-2] + nums[i]`）或不偷（`dp[i-1]`），取最大。

**使用场景：** 相邻约束下的最优化选择。

**模板代码：**
```python
def rob(nums):
    prev2, prev1 = 0, 0           # prev2 = dp[i-2], prev1 = dp[i-1]
    for num in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + num)
    return prev1
```

**复杂度：** O(n) / O(1)。

**易错点：** 状态转移先更新 `prev2` 再用旧值；环形变体要分"抢第一家/不抢第一家"两次 DP。

**关联题目：**
- [[02-Wiki/题目详解/198-打家劫舍]]

### 模板 4：背包 DP —— 0-1 背包 / 完全背包

**一句话原理：** 0-1 背包每件物品**最多选一次** → 容量**倒序**遍历（防止重复选）；完全背包每件可**无限选** → 容量**正序**遍历。

**使用场景：** 选择若干物品满足容量/和约束的最值或方案数。

**模板代码：**
```python
# 0-1 背包：dp[j] = 容量 j 能装的最大价值
def knapsack_01(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for w, v in zip(weights, values):
        for j in range(capacity, w - 1, -1):   # 倒序！防重复选
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[capacity]

# 完全背包：容量正序遍历
def knapsack_complete(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for w, v in zip(weights, values):
        for j in range(w, capacity + 1):       # 正序！可重复选
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[capacity]
```

**复杂度：** O(n × capacity) / O(capacity)。

**易错点：** **倒序 vs 正序**是 0-1/完全背包的分水岭；先物品后容量。

**关联题目：**
- [[02-Wiki/题目详解/416-分割等和子集]]（0-1 背包，容量 = 总和/2）
- [[02-Wiki/题目详解/279-完全平方数]]（完全背包）
- [[02-Wiki/题目详解/139-单词拆分]]（完全背包 + 哈希集）

### 模板 5：零钱兑换 —— 完全背包求最少

**一句话原理：** `dp[j] = min(dp[j], dp[j - coin] + 1)`，求凑成 amount 的最少硬币数。

**使用场景：** 最少/最多用物品凑目标值。

**模板代码：**
```python
def coin_change(coins, amount):
    dp = [amount + 1] * (amount + 1)   # 初始化成"不可能"大值
    dp[0] = 0
    for coin in coins:
        for j in range(coin, amount + 1):
            dp[j] = min(dp[j], dp[j - coin] + 1)
    return dp[amount] if dp[amount] != amount + 1 else -1
```

**复杂度：** O(n × amount) / O(amount)。

**易错点：** 初始化为 `amount + 1` 表示不可达；返回时判断是否仍为不可达。

**关联题目：**
- [[02-Wiki/题目详解/322-零钱兑换]]
- [[02-Wiki/题目详解/279-完全平方数]]

### 模板 6：子序列 DP —— LIS / LCS

**一句话原理：** LIS 用 `dp[i]` 表示"以 nums[i] 结尾的最长递增子序列"，双重循环 O(n²)；LCS 用二维 `dp[i][j]` 表示两串前 i、j 位的最长公共子序列。

**使用场景：** 最长递增子序列、最长公共子序列。

**模板代码：**
```python
def length_of_lis(nums):                  # LIS O(n²)
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

def longest_common_subsequence(text1, text2):   # LCS O(mn)
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

**复杂度：** LIS O(n²)（贪心+二分可 O(n log n)）；LCS O(m·n)。

**易错点：** LIS 的 `dp[i]` 是"以 i 结尾"而非"前 i 个"；LCS 初始化多一维 0 边界。

**关联题目：**
- [[02-Wiki/题目详解/300-最长递增子序列]]
- [[02-Wiki/题目详解/1143-最长公共子序列]]
- [[02-Wiki/题目详解/152-乘积最大子数组]]（线性 DP 同时维护最大/最小）

### 模板 7：编辑距离 —— 二维 DP

**一句话原理：** `dp[i][j]` = word1 前 i 个字符变成 word2 前 j 个字符的最少操作；相等则继承左上，不等则取增/删/改三者最小。

**使用场景：** 字符串转换最小操作数。

**模板代码：**
```python
def edit_distance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i                       # 删 i 次
    for j in range(n + 1):
        dp[0][j] = j                       # 插 j 次
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
    return dp[m][n]
```

**复杂度：** O(m·n) / O(m·n)（可滚动到 O(n)）。

**易错点：** 边界初始化（第 0 行/列）；三个来源的语义（删除/插入/替换）。

**关联题目：**
- [[02-Wiki/题目详解/72-编辑距离]]

### 模板 8：路径 DP —— 不同路径 / 最小路径和

**一句话原理：** `dp[i][j]` 从起点到 (i,j) 的路径数/最小代价；只能向右向下 → `dp[i][j] = dp[i-1][j] + dp[i][j-1]`（或 min）。

**使用场景：** 网格路径计数 / 最小路径和。

**模板代码：**
```python
def unique_paths(m, n):                    # 路径计数
    dp = [[1] * n for _ in range(m)]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
    return dp[m - 1][n - 1]

def min_path_sum(grid):                    # 最小路径和
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = grid[0][0]
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = grid[i][j] + min(dp[i - 1][j], dp[i][j - 1])
    return dp[m - 1][n - 1]
```

**复杂度：** O(m·n) / O(m·n)（可滚动到 O(n)）。

**易错点：** 边界行/列只能单向累加；路径计数 vs 路径和的状态转移不同（+ vs min）。

**关联题目：**
- [[02-Wiki/题目详解/62-不同路径]]
- [[02-Wiki/题目详解/64-最小路径和]]

### 模板 9：区间 DP —— 最长回文子串

**一句话原理：** `dp[i][j]` 表示子串 `s[i..j]` 是否回文；`s[i] == s[j]` 且内部也回文则回文。区间从小往大扩展。

**使用场景：** 回文子串、戳气球、矩阵链乘等"区间"型 DP。

**模板代码：**
```python
def longest_palindrome(s):
    n = len(s)
    dp = [[False] * n for _ in range(n)]
    start = length = 0
    for i in range(n):
        dp[i][i] = True                  # 单个字符回文
    for L in range(2, n + 1):            # 枚举区间长度
        for i in range(n - L + 1):
            j = i + L - 1
            if s[i] == s[j]:
                if L == 2 or dp[i + 1][j - 1]:
                    dp[i][j] = True
                    if L > length:
                        start, length = i, L
    return s[start:start + length]
```

**复杂度：** O(n²) / O(n²)。

**易错点：** 区间 DP 按**长度**从小到大枚举（不能按 i 从小到大）；`L == 2` 特判相邻。

**关联题目：**
- [[02-Wiki/题目详解/5-最长回文子串]]
- [[02-Wiki/题目详解/32-最长有效括号]]（线性 DP 分类讨论）

## 五、易错点清单（专题级全局易错点）

1. **先想清 dp 含义再写代码**：`dp[i]` 是"以 i 结尾"还是"前 i 个"，直接决定方程
2. **初始化仔细**：base case 和边界（第 0 行/列、`dp[0]=0`、不可达值）
3. **遍历顺序**：0-1 背包倒序、完全背包正序、区间 DP 按长度
4. **空间优化**：先写二维再优化一维；滚动变量时注意更新顺序
5. **手动验证**：用小数据推导一遍 dp 表
6. **`[[0]*(n+1)]*(m+1)` 陷阱**：外层乘法共享内层列表引用，必须用列表推导式
