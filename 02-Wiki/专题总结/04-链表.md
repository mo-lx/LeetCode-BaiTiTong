## 一、前备知识（开始本专题前必须会什么）

### 1.1 Python 语法最小示例

| 知识点 | 最小示例 | 本专题用途 | 自检问题 |
|--------|----------|-----------|----------|
| 节点定义 | `class ListNode: def __init__(self, val=0, next=None): self.val=val; self.next=next` | 所有链表题的基础 | 单链表节点有几个属性？ |
| 多变量赋值 | `a, b = b, a` | 指针交换、原地翻转 | 交换需要临时变量吗？ |
| None 检查 | `while cur and cur.next:` | 判环、找中点时防空指针 | 为什么不能只写 `while cur`？ |
| 递归基线 | `if not head: return None` | 递归翻转/归并 | 递归结束条件写在哪？ |

### 1.2 必须理解的本专题约定

- **链表没有下标**：只能从 head 逐个访问（O(n)），无法 O(1) 随机访问
- **改指针三步口诀**：先保存 `nxt = cur.next` → 再改 `cur.next = pre` → 再移动 `pre, cur`
- **画图是硬性要求**：任何指针操作，先画出 3 个以上节点再动手
- **dummy 虚拟头**：用 `dummy = ListNode(0, head)` 统一"头节点可能被修改"的边界，最后 `return dummy.next`

## 二、本质理解（专题核心思想）

**链表 = 离散存储的线性结构**，与数组的连续存储相对。

| 对比 | 数组 | 链表 |
|------|------|------|
| 存储方式 | 连续内存 | 离散内存（指针链接） |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n) | O(1)（已知位置时） |
| 额外空间 | 无 | O(n) 指针存储 |

**核心思维：** 链表题的每一步操作都是在**改指针**。抓住"三个节点视角"（pre / cur / nxt），任何翻转、删除、重排都能画清楚。

```
链表基础
├── 虚拟头节点 dummy：统一头节点处理
├── 快慢指针：判环、找中点、找倒数第 k 个
├── 翻转：迭代三指针 / 递归
├── 合并有序链表：虚拟头 + 双指针
└── 相交：浪漫双指针

链表进阶
├── K 个一组翻转：分组翻转 + 组间重连
├── 随机链表复制：哈希映射 / 三步法
├── 排序链表：归并（找中点 + 合并）
└── LRU 缓存：哈希表 + 双向链表
```

## 三、核心模板技巧

### 模板 1：虚拟头节点 dummy —— 统一边界

**一句话原理：** 在真实头节点前挂一个哨兵，让"改头节点"和"改普通节点"的代码完全一致，最后返回 `dummy.next`。

**使用场景：** 几乎所有**会改变链表结构**的题（删除、翻转、合并、分组重排）。只读遍历不需要。

**模板代码：**
```python
dummy = ListNode(0, head)
# ... 操作链表，一律从 dummy 开始 ...
return dummy.next
```

**复杂度：** O(n) / O(1)。

**易错点：** 返回 `dummy.next` 而非 `dummy`；dummy 值随意但类型必须对。

**关联题目：** 几乎所有链表题，如 [[02-Wiki/题目详解/19-删除链表的倒数第N个节点]]、[[02-Wiki/题目详解/21-合并两个有序链表]]

### 模板 2：反转链表 —— 迭代三指针

**一句话原理：** `pre / cur / nxt` 三指针同步滑动，每次把 `cur.next` 改指向 `pre`。`nxt` 先保存，防止断链。

**使用场景：** 反转整个链表、反转子区间、回文判断（反转后半）。

**模板代码：**
```python
def reverse_list(head):
    pre = None
    cur = head
    while cur:
        nxt = cur.next   # 1. 先保存下一个
        cur.next = pre   # 2. 反转指针
        pre = cur        # 3. pre 前移
        cur = nxt        # 4. cur 前移
    return pre           # 新头节点
```

**复杂度：** O(n) / O(1)。

**易错点：** 必须先 `nxt = cur.next` 再改指针，否则丢链表；返回的是 `pre` 不是 `cur`。

**关联题目：**
- [[02-Wiki/题目详解/206-反转链表]]
- [[02-Wiki/题目详解/234-回文链表]]（找中点 + 反转后半）

### 模板 3：反转链表 —— 递归版

**一句话原理：** 把"反转整个链表"拆成"反转 head.next 起的长子链"，再把 head 接回末尾。核心是 `head.next.next = head`。

**使用场景：** 需要"从后往前"处理时（如某些变体题），或想深入理解递归。迭代版更省空间。

**模板代码：**
```python
def reverse_list_recursive(head):
    if not head or not head.next:
        return head
    new_head = reverse_list_recursive(head.next)
    head.next.next = head   # 让下一个节点指回自己
    head.next = None        # 断掉旧链接，防环
    return new_head
```

**为什么对：** `reverse(head.next)` 返回的是反转后子链的新头；此时 `head.next` 仍是子链的尾节点，把它指回 head 即可完成拼接。

**复杂度：** O(n) / O(n)（递归栈）。

**易错点：** 忘记 `head.next = None` 会成环；base case 要同时处理 `head` 和 `head.next` 为 None。

**关联题目：**
- [[02-Wiki/题目详解/206-反转链表]]
- [[02-Wiki/题目详解/25-K个一组翻转链表]]（递归分组思路）

### 模板 4：合并两个有序链表 —— 虚拟头 + 双指针

**一句话原理：** 双指针比较两链表当前节点，小的先接上；dummy 简化头节点处理，最后接上剩余段。

**使用场景：** 合并有序链表；归并排序链表的合并步骤；合并 K 个链表的基础。

**模板代码：**
```python
def merge_two_lists(l1, l2):
    dummy = ListNode(0)
    cur = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next
    cur.next = l1 if l1 else l2   # 接上剩余段
    return dummy.next
```

**复杂度：** O(n + m) / O(1)。

**易错点：** 别忘记最后接上剩余段；比较用 `<=` 保证稳定性。

**关联题目：**
- [[02-Wiki/题目详解/21-合并两个有序链表]]
- [[02-Wiki/题目详解/23-合并K个升序链表]]
- [[02-Wiki/题目详解/148-排序链表]]

### 模板 5：快慢指针找中点

**一句话原理：** 慢指针走 1 步、快指针走 2 步，快指针到尾时慢指针恰在中点。找中点是"分治/归并"的前置。

**使用场景：** 回文判断、排序链表（归并）、找中位数。

**模板代码：**
```python
def middle_node(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow   # 偶数长度时返回偏右的中点
```

**复杂度：** O(n) / O(1)。

**易错点：** 循环条件必须 `fast and fast.next`，否则 `fast.next.next` 空指针。

**关联题目：**
- [[02-Wiki/题目详解/234-回文链表]]
- [[02-Wiki/题目详解/148-排序链表]]

### 模板 6：快慢指针判环 + 找环入口（Floyd）

**一句话原理：** 两阶段：① 快慢指针相遇则有环；② 相遇后，`slow` 从头出发、`fast` 原地，各走 1 步再相遇处即环入口。

**使用场景：** 判环、找环入口。

**模板代码：**
```python
def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:          # 阶段1：判环
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            break
    else:
        return None                    # 无环
    slow = head                        # 阶段2：找入口
    while slow != fast:
        slow = slow.next
        fast = fast.next
    return slow
```

**为什么阶段 2 成立：** 设 head 到环口距离 a、环口到相遇点距离 b、环长 L，相遇时 `slow` 走了 a+b，`fast` 走了 2(a+b) = a+b+kL ⇒ a+b = kL。从相遇点再走 a 步回到环口，所以 `slow` 从头同步走 a 步必与 `fast` 在环口相遇。

**复杂度：** O(n) / O(1)。

**易错点：** 判环循环条件要同时判 `fast` 和 `fast.next`；`while...else` 的 else 在"正常结束"（无环）时执行。

**关联题目：**
- [[02-Wiki/题目详解/141-环形链表]]
- [[02-Wiki/题目详解/142-环形链表II]]

### 模板 7：删除倒数第 N 个节点 —— 快慢指针 + dummy

**一句话原理：** `fast` 先走 n+1 步，然后 `slow`、`fast` 同步走；`fast` 到结尾时 `slow` 正好停在待删节点的**前驱**。

**为什么是 n+1 步：** 需要停在待删节点的前驱才能执行删除；先走 n+1 步让 `slow` 与 `fast` 保持 n+1 的间距。

**模板代码：**
```python
def remove_nth_from_end(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n + 1):      # fast 先走 n+1 步
        fast = fast.next
    while fast:                 # fast 到尾时 slow 指向前驱
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next
    return dummy.next
```

**复杂度：** O(n) / O(1)。

**易错点：** `fast` 先走的步数是 n+1 不是 n；用 dummy 处理"删除头节点"的边界。

**关联题目：**
- [[02-Wiki/题目详解/19-删除链表的倒数第N个节点]]

### 模板 8：相交链表 —— 浪漫双指针

**一句话原理：** 两个指针各自遍历"自己的链 + 对方的链"，走过相同总长后在交点（或 None）相遇。

**为什么对：** 设 a、b 为两链在交点前的长度，c 为公共段。`pa` 走 a+c+b、`pb` 走 b+c+a，总长相等，必在交点相遇；不相交则同时到 None。

**模板代码：**
```python
def get_intersection_node(head_a, head_b):
    pa, pb = head_a, head_b
    while pa != pb:
        pa = pa.next if pa else head_b   # 走完自己的链就换到对方
        pb = pb.next if pb else head_a
    return pa   # 交点或 None
```

**复杂度：** O(a + b) / O(1)。

**易错点：** 换链用 `pa.next if pa else head_b`，不是 `if pa is None`（pa 可能中途为 None 但还没走完总长——实际上循环条件已保证走到末尾时同步交换）。

**关联题目：**
- [[02-Wiki/题目详解/160-相交链表]]

### 模板 9：K 个一组翻转链表

**一句话原理：** 先检查剩余是否够 k 个，够则对这一段做局部翻转（复用模板 2），再组间重连，用 `pre` 记录上一组的末尾。

**使用场景：** 分组翻转；两两交换（k=2 的特例）。

**模板代码：**
```python
def reverse_k_group(head, k):
    dummy = ListNode(0, head)
    pre = dummy
    while True:
        cur = pre
        for _ in range(k):          # 检查是否够 k 个
            cur = cur.next
            if not cur:
                return dummy.next
        group_head = pre.next       # 本组头
        next_group = cur.next       # 下一组头（先保存）
        pre.next = reverse_sublist(group_head, k)  # 翻转本组
        group_head.next = next_group              # 组间重连
        pre = group_head            # 更新 pre 为本组尾
```

```python
def reverse_sublist(head, k):       # 翻转 head 起 k 个节点
    pre, cur = None, head
    for _ in range(k):
        nxt = cur.next
        cur.next = pre
        pre = cur
        cur = nxt
    return pre
```

**复杂度：** O(n) / O(1)。

**易错点：** 翻转前必须保存 `next_group`；翻转后 `group_head` 变成组尾，要负责接上下一组。

**关联题目：**
- [[02-Wiki/题目详解/25-K个一组翻转链表]]
- [[02-Wiki/题目详解/24-两两交换链表中的节点]]

### 模板 10：随机链表的复制 —— 三步法

**一句话原理：** ① 每个节点后插入克隆节点；② 用原节点的 random 给克隆节点的 random 赋值（`clone.random = cur.random.next`）；③ 拆分成原链和新链。

**为什么不需要哈希表：** 克隆节点紧跟在原节点后面，所以"原节点.random.next"就是"克隆节点.random"，实现 O(1) 空间。

**模板代码：**
```python
def copy_random_list(head):
    if not head:
        return None
    # ① 插入克隆节点
    cur = head
    while cur:
        nxt = cur.next
        cur.next = ListNode(cur.val, nxt)
        cur = nxt
    # ② 处理 random
    cur = head
    while cur:
        if cur.random:
            cur.next.random = cur.random.next
        cur = cur.next.next
    # ③ 拆分
    new_head = head.next
    cur = head
    while cur:
        clone = cur.next
        cur.next = clone.next
        if clone.next:
            clone.next = clone.next.next
        cur = cur.next
    return new_head
```

**复杂度：** O(n) / O(1)。

**易错点：** 三步顺序不能乱；拆分时要同时恢复原链和接好新链。

**关联题目：**
- [[02-Wiki/题目详解/138-随机链表的复制]]

### 模板 11：排序链表 —— 归并排序

**一句话原理：** 链表归并 = 找中点（模板 5）+ 递归排序两半 + 合并（模板 4）。因为链表无法 O(1) 随机访问，归并排序是 O(n log n) 的最优选择。

**模板代码：**
```python
def sort_list(head):
    if not head or not head.next:
        return head
    slow, fast = head, head.next          # fast 从 head.next 出发 → 偶数长度取左中点
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    mid = slow.next                        # 右半头
    slow.next = None                       # 断开两半
    left = sort_list(head)
    right = sort_list(mid)
    return merge_two_lists(left, right)    # 复用模板4
```

**复杂度：** O(n log n) / O(log n)（递归栈）。

**易错点：** 找中点时 `fast = head.next` 让偶数长度时左半更短，避免死循环；必须 `slow.next = None` 断开。

**关联题目：**
- [[02-Wiki/题目详解/148-排序链表]]

### 模板 12：合并 K 个升序链表 —— 分治

**一句话原理：** 两两合并（归并思想），把"一次合并 K 个"变成 log K 轮两两合并，总复杂度 O(n log K)。

**模板代码：**
```python
def merge_k_lists(lists):
    if not lists:
        return None
    step = 1
    while step < len(lists):
        for i in range(0, len(lists) - step, step * 2):
            lists[i] = merge_two_lists(lists[i], lists[i + step])  # 复用模板4
        step *= 2
    return lists[0]
```

**复杂度：** O(n log K) / O(1)（迭代分治）或 O(log K)（递归栈）。

**易错点：** 分治的步长翻倍逻辑（`step *= 2`）；空列表数组要判空。

**关联题目：**
- [[02-Wiki/题目详解/23-合并K个升序链表]]

### 模板 13：LRU 缓存 —— 哈希表 + 双向链表

**一句话原理：** 哈希表 O(1) 定位节点，双向链表 O(1) 增删（头插 + 尾删）。每次访问把节点移到头部，容量满就删尾部。

**使用场景：** 需要"最近最少使用"淘汰策略的缓存设计。

**模板代码：**
```python
class DLinkedNode:
    def __init__(self, key=0, value=0):
        self.key, self.value = key, value
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}                     # key -> node
        self.head = DLinkedNode()           # 虚拟头尾
        self.tail = DLinkedNode()
        self.head.next = self.tail
        self.tail.prev = self.head

    def get(self, key):
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._move_to_head(node)
        return node.value

    def put(self, key, value):
        if key in self.cache:
            node = self.cache[key]
            node.value = value
            self._move_to_head(node)
        else:
            node = DLinkedNode(key, value)
            self.cache[key] = node
            self._add_to_head(node)
            if len(self.cache) > self.capacity:
                removed = self._remove_tail()
                del self.cache[removed.key]

    def _add_to_head(self, node):
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def _remove_node(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _move_to_head(self, node):
        self._remove_node(node)
        self._add_to_head(node)

    def _remove_tail(self):
        node = self.tail.prev
        self._remove_node(node)
        return node
```

**复杂度：** get / put 均 O(1) / 空间 O(capacity)。

**易错点：** 双向链表增删要同时改 `prev` 和 `next` 两对指针；哈希表存 key→node，删除时用 `node.key` 回删。

**关联题目：**
- [[02-Wiki/题目详解/146-LRU缓存]]

## 四、模板选择决策（什么时候用哪个）

```
链表题第一问：要不要改变链表结构（翻转/删除/重排）？
├── 是 → dummy 虚拟头 + 画图
│   ├── 整体/局部翻转 → 模板2 迭代三指针 / 模板3 递归
│   ├── 删除节点 → 模板7 快慢指针找前驱
│   ├── 成组重排 → 模板9 K个一组翻转
│   ├── 复制带 random → 模板10 三步法
│   └── 排序 → 模板11 归并
├── 否 → 只读遍历
│   ├── 判环/找环入口 → 模板6 Floyd
│   ├── 找中点/倒数第k → 模板5/7 快慢指针
│   ├── 合并有序 → 模板4 双指针
│   └── 求交点 → 模板8 浪漫双指针
└── 特殊结构 → 模板13 哈希+双向链表（LRU）
```

## 五、易错点清单（专题级全局易错点）

1. **画图！画图！画图！** 链表操作必须画图，否则指针乱指
2. **改指针前先保存**：`nxt = cur.next` 永远是第一步
3. **None 检查**：`while cur and cur.next`，特别是判环、找中点
4. **dummy 的使用**：会改头节点的题一律用 `dummy`，返回 `dummy.next`
5. **断链**：删除/断开两半时，确保前驱的 next 已指向正确位置
6. **递归返回值**：递归翻转返回新头；递归 base case 要同时覆盖 `head` 和 `head.next`
