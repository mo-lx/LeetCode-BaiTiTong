### 1.2 必须理解的本专题约定

- **图的两种表示**：邻接表（`node -> [neighbors]`）最常用；邻接矩阵（二维表）适合稠密图
- **网格 = 隐式图**：每个格子有 4 个邻居（上下左右），用 `dirs` + 边界判断
- **visited 的两种方式**：额外 `set/数组`（通用）vs 原地修改（网格题"沉岛"把 `'1'` 改 `'0'`）
- **DFS vs BFS 选型**：求"最少步数/最短路径"用 BFS（首次到达即最短）；求"连通性/所有路径"用 DFS

## 二、本质理解（专题核心思想）

**图 = 节点的集合 + 节点之间的连接关系。** 图是"链表 → 二叉树 → 多叉树 → 图"的最终泛化（可以成环）。

```
链表 → 二叉树 → 多叉树 → 图
（线性） （二叉） （多叉） （有环）
```

**图论四类核心问题：**
| 问题 | 首选工具 |
|------|----------|
| 连通性 / 路径搜索 | DFS |
| 最短步数 / 最少层数 | BFS |
| 依赖关系 / 是否成环 | 拓扑排序 |
| 动态连通性 / 分组 | 并查集 |

## 三、核心模板技巧

### 模板 1：图 DFS

**一句话原理：** 递归深入直到尽头再回溯；`visited` 防止在环中死循环。外层循环处理非连通图。

**使用场景：** 连通分量、路径搜索、判断可达。

**模板代码：**
```python
def dfs_graph(graph):
    visited = set()

    def dfs(node):
        if node in visited:
            return
        visited.add(node)
        # 处理当前节点
        for neighbor in graph[node]:
            dfs(neighbor)

    for node in graph:              # 遍历所有起点，覆盖非连通图
        if node not in visited:
            dfs(node)
```

**复杂度：** O(V + E) / O(V)（递归栈）。

**易错点：** 必须在访问前加入 `visited`，否则环会死循环。

**关联题目：** [[02-Wiki/题目详解/200-岛屿数量]]（网格版）

### 模板 2：图 BFS —— 最短步数

**一句话原理：** 队列按层扩散，逐层步数 +1；每个节点首次被访问时所在层数即最短步数。

**使用场景：** 求最短路径/最少步数（无权图）。

**模板代码：**
```python
from collections import deque

def bfs_shortest(start, target, graph):
    q = deque([start])
    visited = {start}
    step = 0
    while q:
        size = len(q)                # 本层节点数
        for _ in range(size):
            node = q.popleft()
            if node == target:
                return step
            for neighbor in graph[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    q.append(neighbor)
        step += 1
    return -1
```

**复杂度：** O(V + E) / O(V)。

**易错点：** 用 `visited` 在入队时就标记（防止重复入队）；分层用 `size = len(q)`。

**关联题目：** 网格 BFS 见模板 4

### 模板 3：网格 DFS —— 岛屿问题（沉岛法）

**一句话原理：** 遍历网格，遇到 `'1'` 就计数 + DFS 把它所在的整个岛"沉掉"（改为 `'0'`），避免重复计数。

**使用场景：** 岛屿数量、被围绕的区域、最大岛屿面积等网格连通性题。

**模板代码：**
```python
def num_islands(grid):
    if not grid:
        return 0
    m, n = len(grid), len(grid[0])
    count = 0

    def dfs(i, j):
        if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != '1':
            return
        grid[i][j] = '0'            # 沉岛：原地标记已访问
        dfs(i + 1, j)
        dfs(i - 1, j)
        dfs(i, j + 1)
        dfs(i, j - 1)

    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                count += 1
                dfs(i, j)
    return count
```

**复杂度：** O(m × n) / O(m × n)（最坏递归栈）。

**易错点：** 越界判断 + 沉岛（改值）要在同一条件里；四方向别漏。

**关联题目：**
- [[02-Wiki/题目详解/200-岛屿数量]]

### 模板 4：多源 BFS —— 腐烂的橘子

**一句话原理：** 把所有腐烂橘子（多个起点）同时入队，逐层扩散；层数即分钟数。`fresh` 计数判断是否全部腐烂。

**使用场景：** 从多个源头同时扩散的最短时间/最少步数。

**模板代码：**
```python
from collections import deque

def oranges_rotting(grid):
    m, n = len(grid), len(grid[0])
    q = deque()
    fresh = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == 2:
                q.append((i, j))
            elif grid[i][j] == 1:
                fresh += 1
    if fresh == 0:
        return 0

    minutes = 0
    dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]
    while q and fresh > 0:
        minutes += 1
        for _ in range(len(q)):
            i, j = q.popleft()
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                    fresh -= 1
                    grid[ni][nj] = 2
                    q.append((ni, nj))
    return minutes if fresh == 0 else -1
```

**复杂度：** O(m × n) / O(m × n)。

**易错点：** 多个起点先全部入队再逐层扩散；`fresh > 0` 作为循环条件之一。

**关联题目：**
- [[02-Wiki/题目详解/994-腐烂的橘子]]

### 模板 5：拓扑排序 —— Kahn（BFS）/ DFS

**一句话原理：** 拓扑排序 = 给有向无环图（DAG）排出一个线性顺序，使每条边 u→v 满足 u 在 v 前。Kahn 用"入度为 0 的节点先出"；若处理节点数 < 总节点数则说明有环。

**使用场景：** 课程表/依赖顺序/判断是否有环。

**模板代码（Kahn / BFS）：**
```python
from collections import deque

def can_finish(num_courses, prerequisites):
    graph = [[] for _ in range(num_courses)]
    indegree = [0] * num_courses
    for course, pre in prerequisites:
        graph[pre].append(course)
        indegree[course] += 1

    q = deque([i for i in range(num_courses) if indegree[i] == 0])
    count = 0
    while q:
        node = q.popleft()
        count += 1
        for neighbor in graph[node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                q.append(neighbor)
    return count == num_courses      # 处理完所有节点 = 无环
```

**模板代码（DFS 后序检测环）：**
```python
def can_finish_dfs(num_courses, prerequisites):
    graph = [[] for _ in range(num_courses)]
    for course, pre in prerequisites:
        graph[pre].append(course)
    visited = [0] * num_courses      # 0 未访问 / 1 访问中 / 2 已完成

    def dfs(node):
        if visited[node] == 1:       # 访问中又回到自己 → 有环
            return False
        if visited[node] == 2:
            return True
        visited[node] = 1
        for neighbor in graph[node]:
            if not dfs(neighbor):
                return False
        visited[node] = 2
        return True

    return all(dfs(i) for i in range(num_courses))
```

**复杂度：** O(V + E) / O(V + E)。

**易错点：** Kahn 用入度数组 + 队列；DFS 用三色标记（0/1/2）检测环；无环才有拓扑序。

**关联题目：**
- [[02-Wiki/题目详解/207-课程表]]

### 模板 6：并查集（Union-Find）

**一句话原理：** 用数组记录每个元素的"父节点"，支持 O(α(n)) 的"合并"与"查询是否同组"。路径压缩 + 按秩合并保证近乎 O(1)。

**使用场景：** 动态连通性、分组（朋友圈/省份）、判断成环（边两端已在同一集合 → 成环）、岛屿连通。

**模板代码：**
```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n          # 按秩合并

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])   # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False             # 已同组 → 说明成环（返回 False 供判断）
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True

    def connected(self, x, y):
        return self.find(x) == self.find(y)
```

**复杂度：** 近似 O(1)（反阿克曼函数）/ O(n)。

**易错点：** `union` 前先 `find` 根节点；路径压缩递归写法注意 `parent[x]` 更新。

**关联题目：** 200 岛屿数量可用并查集；Hot 100 无独立并查集题，但连通性题（如省份数量）通用。

### 模板 7：Trie（前缀树）—— 字典树

**一句话原理：** 用嵌套字典/数组按字符分叉建树，`is_end` 标记单词结尾。支持 O(L)（L=单词长度）的插入/查找/前缀查询。

**使用场景：** 前缀匹配、词频统计、自动补全。注意：Trie 本质是**树型结构**，不属于图，此处仅收录供查用。

**模板代码：**
```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                node.children[ch] = Trie()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):
        node = self._find(word)
        return node is not None and node.is_end

    def starts_with(self, prefix):
        return self._find(prefix) is not None

    def _find(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                return None
            node = node.children[ch]
        return node
```

**复杂度：** O(L) / O(总字符数)。

**易错点：** `search` 和 `starts_with` 的区别在于是否要求 `is_end`。

## 四、模板选择决策（什么时候用哪个）

```
图题先问：要求什么？
├── 连通分量 / 可达性 / 路径 → 模板1 DFS / 模板3 网格DFS
├── 最少步数 / 最短时间 → 模板2 BFS / 模板4 多源BFS
├── 依赖顺序 / 是否有环（DAG） → 模板5 拓扑排序
├── 动态合并分组 / 判断成环 → 模板6 并查集
└── 前缀匹配 / 字典查询 → 模板7 Trie

BFS vs DFS 快速判断：
├── 求最短 → BFS（首次到达即最短）
└── 求连通/枚举 → DFS（实现简单）
```

## 五、易错点清单（专题级全局易错点）

1. **DFS vs BFS 选型**：求最短路径/最少步数用 BFS；求连通性/路径用 DFS
2. **visited 两种方式**：额外 set（通用）vs 原地修改（网格"沉岛"）
3. **多源 BFS**：多个起点同时入队，逐层扩散（烂橘子）
4. **拓扑排序**：Kahn 用入度；DFS 用三色标记；处理数 < 总数 = 有环
5. **Trie 内存**：每字符一个节点，字符串量大时内存大
6. **并查集**：必须路径压缩 + 按秩合并才能近似 O(1)；`union` 前先 `find`
