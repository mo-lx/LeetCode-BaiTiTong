## 一、前备知识（开始本专题前必须会什么）

### 1.1 Python 语法最小示例

| 知识点 | 最小示例 | 本专题用途 | 自检问题 |
|--------|----------|-----------|----------|
| 递归 | `def f(x): if base: return; f(x-1)` | 回溯本身就是递归 | 递归三要素是什么？ |
| 深拷贝 | `res.append(path[:])` | 保存结果必须复制 | `append(path)` 有什么问题？ |
| 列表引用语义 | `path.pop()` | 撤销选择 | 为什么递归后要 pop？ |
| 集合去重 | `used[i] = True / False` | visited 标记 | 标记和撤销要对称吗？ |

### 1.2 必须理解的本专题约定

- **回溯 = 决策树的遍历**：路径（`path`）/ 选择列表（`for` 循环）/ 结束条件（`if`）
- **`visited` vs `start` 的选用**：排列关注顺序 → `visited`；组合/子集不关注顺序 → `start` 保证不回头
- **含重复元素 → 先排序**，再"同层跳过重复"去重
- **撤销必须彻底**：做了什么选择，递归返回后一定还原

## 二、本质理解（专题核心思想）

labuladong 对回溯的定位：

> **回溯 = 决策树的遍历过程**

**回溯三要素 → 代码映射：**

| 要素 | 说明 | 代码体现 |
|------|------|----------|
| 路径 | 已经做出的选择 | `path` 列表 |
| 选择列表 | 当前可以做的选择 | `for` 循环遍历 |
| 结束条件 | 到达决策树底层 | `if` 判断后 `return` |

**回溯 vs 其他算法：**

| 算法 | 关系 | 区别 |
|------|------|------|
| DFS | 回溯 = DFS + 状态重置 | DFS 只管遍历，回溯遍历后要撤销 |
| 暴力穷举 | 回溯 = 优雅的暴力 | 回溯用递归实现，结构清晰 |
| 动态规划 | 回溯 = DP 无记忆版本 | DP 有重叠子问题优化，回溯没有 |

## 三、核心模板技巧

### 模板 1：标准回溯框架

**一句话原理：** 三个动作循环：做选择 → 进入下一层 → 撤销选择；`result.append(path[:])` 深拷贝保存结果。

**使用场景：** 排列/组合/子集/分割/棋盘等"决策树"类问题的统一骨架。

**模板代码：**
```python
result = []

def backtrack(path, choices):
    if "满足结束条件":
        result.append(path[:])      # 深拷贝！不是 path
        return
    for choice in choices:
        # 剪枝（可选）
        if "不合法":
            continue
        # 做选择
        path.append(choice)
        backtrack(path, new_choices)
        # 撤销选择
        path.pop()
```

**复杂度：** 视具体问题（全排列 O(n·n!)、子集 O(n·2^n)）。

**易错点：** 深拷贝；撤销彻底；剪枝放在做选择之前。

**关联题目：** 以下所有模板的基础。

### 模板 2：全排列 —— visited 标记

**一句话原理：** 每次从**所有**元素里选一个未用的（`used` 排除），所以顺序不同算不同结果 → 排列。

**使用场景：** 全排列、含重复元素排列（配模板 5 去重）。

**模板代码：**
```python
def permute(nums):
    res = []
    used = [False] * len(nums)

    def backtrack(path):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack(path)
            path.pop()
            used[i] = False

    backtrack([])
    return res
```

**复杂度：** O(n · n!) / O(n)。

**易错点：** `used[i]` 标记和撤销必须对称；路径长度达到 n 即结束。

**关联题目：**
- [[02-Wiki/题目详解/46-全排列]]

### 模板 3：子集 —— start 控制不回头

**一句话原理：** 从 `start` 开始选，保证不会回头选到前面的元素 → 顺序无关 → 子集。**每个节点**都加入结果。

**使用场景：** 子集、组合（start 参数是组合/子集的标志）。

**模板代码：**
```python
def subsets(nums):
    res = []

    def backtrack(start, path):
        res.append(path[:])             # 每个节点都是子集
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)      # 从 i+1 开始，不回头
            path.pop()

    backtrack(0, [])
    return res
```

**复杂度：** O(n · 2^n) / O(n)。

**易错点：** 递归传 `i + 1` 而非 `start`；子集是"每个节点都收集"。

**关联题目：**
- [[02-Wiki/题目详解/78-子集]]

### 模板 4：组合总和 —— start + 剪枝

**一句话原理：** 组合求和，`start` 控制不重复；**可重复选**时递归传 `i` 而非 `i+1`；排序后 `candidates[i] > remaining` 直接 break 剪枝。

**使用场景：** 组合总和、组合求和（可重复/不可重复选）。

**模板代码：**
```python
def combination_sum(candidates, target):
    res = []
    candidates.sort()                    # 排序便于剪枝

    def backtrack(start, path, remaining):
        if remaining == 0:
            res.append(path[:])
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remaining:   # 剪枝
                break
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])  # 可重复选 → i
            path.pop()

    backtrack(0, [], target)
    return res
```

**复杂度：** 指数级 / O(target)。

**易错点：** 可重复选传 `i`、不可重复选传 `i+1`；剪枝前提是已排序。

**关联题目：**
- [[02-Wiki/题目详解/39-组合总和]]
- [[02-Wiki/题目详解/131-分割回文串]]（同为"切割+选择"回溯）

### 模板 5：去重变体 —— 排序 + 同层跳过（含重复元素）

**一句话原理：** 先排序，重复元素只让**第一个**参与本层选择（`i > 0 and nums[i] == nums[i-1] and not used[i-1]` 则跳过），避免产生重复结果。

**使用场景：** 含重复元素的排列/组合/子集（子集 II、组合总和 II）。Hot 100 无直接题，但面试高频、是排列的常见延伸。

**模板代码（含重复元素的全排列）：**
```python
def permute_unique(nums):
    nums.sort()
    res = []
    used = [False] * len(nums)

    def backtrack(path):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
                continue                    # 同层去重：前一个相同元素未用则跳过
            used[i] = True
            path.append(nums[i])
            backtrack(path)
            path.pop()
            used[i] = False

    backtrack([])
    return res
```

**为什么是 `not used[i-1]`：** 保证同一层上相同值的元素只取第一个；若 `used[i-1]` 为 True 说明是**上一层**用过的，可以放行。

**复杂度：** O(n · n!)（最坏）/ O(n)。

**易错点：** 去重必须"先排序 + 同层跳过"；条件里的 `not used[i-1]` 是灵魂。

**关联题目：** 90 子集 II、40 组合总和 II（延伸题，无详解文件）

### 模板 6：单词搜索 —— 网格回溯

**一句话原理：** 在网格上做回溯：匹配当前字符后，向四方向探索，用临时标记 `#` 防止重复走，回溯时还原。

**使用场景：** 网格上找单词/路径（关联 [[02-Wiki/专题总结/07-图论]] 网格 DFS）。

**模板代码：**
```python
def exist(board, word):
    m, n = len(board), len(board[0])

    def backtrack(i, j, k):
        if k == len(word):
            return True
        if i < 0 or i >= m or j < 0 or j >= n or board[i][j] != word[k]:
            return False
        temp, board[i][j] = board[i][j], '#'    # 标记已访问
        res = (backtrack(i + 1, j, k + 1) or
               backtrack(i - 1, j, k + 1) or
               backtrack(i, j + 1, k + 1) or
               backtrack(i, j - 1, k + 1))
        board[i][j] = temp                      # 撤销标记
        return res

    for i in range(m):
        for j in range(n):
            if backtrack(i, j, 0):
                return True
    return False
```

**复杂度：** O(m·n·4^L)（L 为单词长度）/ O(L)。

**易错点：** 用临时字符标记而非 visited 集合；撤销标记必须还原。

**关联题目：**
- [[02-Wiki/题目详解/79-单词搜索]]

### 模板 7：N 皇后 —— 对角线标记

**一句话原理：** 逐行放皇后，用三个集合标记已占用的**列、主对角线（row-col）、副对角线（row+col）**，放置冲突则跳过。

**使用场景：** 棋盘/约束满足类回溯。

**模板代码：**
```python
def solve_n_queens(n):
    res = []
    cols = set()
    diag1 = set()       # 主对角线：row - col 为常数
    diag2 = set()       # 副对角线：row + col 为常数

    def backtrack(row, path):
        if row == n:
            res.append([''.join(r) for r in path])
            return
        for col in range(n):
            if col in cols or (row - col) in diag1 or (row + col) in diag2:
                continue
            cols.add(col)
            diag1.add(row - col)
            diag2.add(row + col)
            path.append(['Q' if c == col else '.' for c in range(n)])
            backtrack(row + 1, path)
            path.pop()
            cols.remove(col)
            diag1.remove(row - col)
            diag2.remove(row + col)

    backtrack(0, [])
    return res
```

**复杂度：** O(n!) / O(n)。

**易错点：** 对角线用 `row - col` 和 `row + col` 两个不变量；标记与撤销对称。

**关联题目：**
- [[02-Wiki/题目详解/51-N皇后]]

## 四、模板选择决策（什么时候用哪个）

```
回溯题先问：结果是否关注顺序？
├── 关注顺序 → 模板2 全排列（visited 标记）
│   └── 含重复元素 → 模板5 排序+同层去重
├── 不关注顺序 → 模板3 子集 / 模板4 组合（start 参数）
│   └── 求固定和 → 模板4 组合总和（+剪枝）
├── 网格上找路径 → 模板6 单词搜索（临时标记）
└── 棋盘/约束满足 → 模板7 N皇后（对角线标记）

剪枝三分类：
├── 可行性剪枝：剩余不足以完成 → 提前 return
├── 去重剪枝：同层重复值跳过（模板5）
└── 排序剪枝：已排序后越界即 break（模板4）
```

## 五、易错点清单（专题级全局易错点）

1. **深拷贝**：`res.append(path[:])` 而非 `res.append(path)`，最常见 bug
2. **撤销要彻底**：做了什么选择，递归后一定还原（path.pop、used 还原、标记还原）
3. **剪枝是灵魂**：不剪枝 = 裸暴力；剪枝后效率大幅提升
4. **排序预处理**：组合总和、含重复元素的排列/组合，先排序
5. **visited vs start**：排列用 visited（顺序相关），组合/子集用 start（顺序无关）
6. **可重复选**：递归传 `i`（如组合总和）vs 不可重复选传 `i+1`
