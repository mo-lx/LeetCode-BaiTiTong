## 二、本质理解（专题核心思想）

**二叉树 = 链表的分叉版。** 每个节点有两个 next（left 和 right），是"节点 + 指针"结构从一维到二维的延伸（关联 [[02-Wiki/专题总结/04-链表]]）。

**二叉树是理解递归的入口：** 几乎所有二叉树问题都能递归解决，且模式固定。

```
二叉树解题
├── 遍历法：遍历整棵树，过程中更新全局变量
│   → "打擂台"，适合统计类、查找类
│   → 前/中/后序决定处理时机
└── 分解法：定义递归返回值，用子问题结果构造当前答案
    → "分治"，适合子树属性类、构造类
    → 关键是明确递归函数的"含义"
```

**三个位置的时机与典型应用：**

| 位置 | 时机 | 典型应用 |
|------|------|----------|
| 前序 | 刚进入节点，还没处理子树 | 构造、复制、翻转 |
| 中序 | 左子树处理完，右子树还没处理 | BST 相关（中序有序） |
| 后序 | 左右子树都处理完 | 求深度、路径、直径 |

## 三、核心模板技巧

### 模板 1：DFS 遍历框架（递归）

**一句话原理：** 递归遍历天然就是栈式调用，三个位置（前/中/后序）对应"进入节点 / 左子树返回后 / 右子树返回后"三个时机。

**使用场景：** 几乎所有树题的基础骨架。前序适合"自上而下传参"（如 114 展开为链表），后序适合"自下而上收集信息"（如 104 深度、236 LCA）。

**模板代码：**
```python
def traverse(root):
    if not root:            # base case
        return
    # 前序位置（刚进入节点时）
    traverse(root.left)
    # 中序位置（左子树返回后）
    traverse(root.right)
    # 后序位置（右子树返回后）
```

**复杂度：** O(n) / O(h)，h 为树高。

**易错点：** 处理节点的代码放在哪个位置，决定它是前/中/后序，直接影响结果。

**关联题目：** 几乎全部，如 [[02-Wiki/题目详解/226-翻转二叉树]]、[[02-Wiki/题目详解/543-二叉树的直径]]

### 模板 2：迭代遍历 —— 显式栈

**一句话原理：** 用显式栈模拟递归调用栈。前序"根→左→右"，中序"左→根→右"，栈的入栈顺序与处理顺序相反。

**使用场景：** 要求 O(1) 额外空间（Morris 之外）、避免递归栈溢出（树很深时）、或面试考察非递归写法。

**模板代码（前序）：**
```python
def preorder_traversal(root):
    res = []
    stack = [root]
    while stack:
        node = stack.pop()
        if not node:
            continue
        res.append(node.val)
        stack.append(node.right)   # 先入右，后弹出（LIFO）
        stack.append(node.left)
    return res
```

**模板代码（中序）：**
```python
def inorder_traversal(root):
    res = []
    stack = []
    cur = root
    while stack or cur:
        while cur:                  # 一路向左
            stack.append(cur)
            cur = cur.left
        node = stack.pop()          # 出栈即处理
        res.append(node.val)
        cur = node.right            # 转向右子树
    return res
```

**复杂度：** O(n) / O(h)。

**易错点：** 前序用"先右后左"入栈保证左先出；中序要"先一路压左"再出栈。

**关联题目：**
- [[02-Wiki/题目详解/94-二叉树的中序遍历]]
- [[02-Wiki/题目详解/114-二叉树展开为链表]]

### 模板 3：BFS 层序遍历

**一句话原理：** 队列按层入队，`level_size = len(q)` 固定本层节点数，实现逐层输出。

**使用场景：** 按层遍历、右视图、二叉树最小深度（BFS 找到第一个叶子即最短路径）。

**模板代码：**
```python
from collections import deque

def level_order(root):
    if not root:
        return []
    res = []
    q = deque([root])
    while q:
        level_size = len(q)          # 关键：先记录本层大小
        level = []
        for _ in range(level_size):
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)
    return res
```

**复杂度：** O(n) / O(n)（队列最宽一层）。

**易错点：** 必须先 `level_size = len(q)` 再循环，否则会把下一层的节点也放进本层。

**关联题目：**
- [[02-Wiki/题目详解/102-二叉树的层序遍历]]
- [[02-Wiki/题目详解/199-二叉树的右视图]]

### 模板 4：最大深度 —— 后序 + 分解法

**一句话原理：** 根节点深度 = 1 + max(左子树深度, 右子树深度)，递归返回子树深度。

**使用场景：** 所有需要"子树信息向上汇聚"的题（深度、直径、最大路径和）的基础。

**模板代码：**
```python
def max_depth(root):
    if not root:
        return 0
    left_depth = max_depth(root.left)
    right_depth = max_depth(root.right)
    return 1 + max(left_depth, right_depth)
```

**复杂度：** O(n) / O(h)。

**易错点：** 空节点返回 0 不是 -1（深度按边数还是节点数要看清题意）。

**关联题目：**
- [[02-Wiki/题目详解/104-二叉树的最大深度]]
- [[02-Wiki/题目详解/543-二叉树的直径]]

### 模板 5：翻转二叉树 —— 前序 + 遍历法

**一句话原理：** 在前序位置交换左右孩子，再递归翻转子树。

**使用场景：** 对称/镜像变换类问题。

**模板代码：**
```python
def invert_tree(root):
    if not root:
        return None
    root.left, root.right = root.right, root.left   # 前序位置交换
    invert_tree(root.left)
    invert_tree(root.right)
    return root
```

**复杂度：** O(n) / O(h)。

**易错点：** 交换必须在递归左右子树**之前**（前序），否则交换后递归顺序不影响结果但逻辑要自洽。

**关联题目：**
- [[02-Wiki/题目详解/226-翻转二叉树]]
- [[02-Wiki/题目详解/101-对称二叉树]]（对称 = 两树互为镜像）

### 模板 6：对称二叉树 —— 递归比较

**一句话原理：** 对称 ⇔ 左子树和右子树互为镜像，即 `is_mirror(left, right)`：值相等、left.left 与 right.right 镜像、left.right 与 right.left 镜像。

**使用场景：** 树的结构对称性判断。

**模板代码：**
```python
def is_symmetric(root):
    def is_mirror(a, b):
        if not a and not b:
            return True
        if not a or not b:
            return False
        return (a.val == b.val
                and is_mirror(a.left, b.right)
                and is_mirror(a.right, b.left))
    return is_mirror(root, root)
```

**复杂度：** O(n) / O(h)。

**易错点：** 镜像比较是"左对右、右对左"，不是"左对左、右对右"。

**关联题目：**
- [[02-Wiki/题目详解/101-对称二叉树]]

### 模板 7：验证 BST —— 中序 + 全局变量

**一句话原理：** BST 的中序遍历是**严格递增**序列，所以中序遍历时检查"当前值 > 前一个值"即可。

**为什么不能用"只比较当前节点和左右子节点"：** BST 要求**所有**左子树节点 < 根 < **所有**右子树节点，只比较相邻会漏掉跨层违反（如根是 5，右子树左节点是 3）。

**模板代码：**
```python
def is_valid_bst(root):
    prev = float('-inf')

    def inorder(node):
        nonlocal prev
        if not node:
            return True
        if not inorder(node.left):
            return False
        if node.val <= prev:          # 严格递增，等于也不行
            return False
        prev = node.val
        return inorder(node.right)

    return inorder(root)
```

**复杂度：** O(n) / O(h)。

**易错点：** 用 `<=`（严格递增）；或用"上下界传参"写法：`is_bst(node, lo, hi)` 检查 `lo < node.val < hi`。

**关联题目：**
- [[02-Wiki/题目详解/98-验证二叉搜索树]]

### 模板 8：BST 第 K 小 —— 中序 + 计数

**一句话原理：** 中序遍历 BST 就是有序序列，数到第 k 个即可。

**使用场景：** 第 k 小 / 第 k 大（第 k 大 = 逆中序）。

**模板代码：**
```python
def kth_smallest(root, k):
    count = 0
    result = None

    def inorder(node):
        nonlocal count, result
        if not node or result is not None:
            return
        inorder(node.left)
        count += 1
        if count == k:
            result = node.val
            return
        inorder(node.right)

    inorder(root)
    return result
```

**复杂度：** O(h + k) / O(h)。

**易错点：** 剪枝：找到 k 后提前返回（用 `result is not None` 判断）。

**关联题目：**
- [[02-Wiki/题目详解/230-BST第K小的元素]]

### 模板 9：最近公共祖先（LCA）—— 后序 + 分解法

**一句话原理：** 递归在每个节点返回"子树里找到的 p 或 q"；若左右都返回非空，则当前节点是 LCA；否则返回非空的那一侧。

**使用场景：** 树中两节点的最近公共祖先。

**模板代码：**
```python
def lowest_common_ancestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    if left and right:          # p、q 分别在左右子树 → 当前是 LCA
        return root
    return left or right        # 返回找到的那一侧
```

**复杂度：** O(n) / O(h)。

**易错点：** base case 包含 `root == p or root == q`（p/q 本身就是祖先时）；后序保证自下而上首次遇到"左右各一"。

**关联题目：**
- [[02-Wiki/题目详解/236-二叉树的最近公共祖先]]

### 模板 10：从前序+中序构造二叉树

**一句话原理：** 前序第一个是根；在中序中定位根，左边是左子树、右边是右子树；`left_size` 用于切分前序的左右区间。哈希表加速"根在中序的位置"。

**使用场景：** 由遍历序列重建二叉树。

**模板代码：**
```python
def build_tree(preorder, inorder):
    index_map = {val: i for i, val in enumerate(inorder)}

    def build(pre_l, pre_r, in_l, in_r):
        if pre_l > pre_r:
            return None
        root_val = preorder[pre_l]
        root = TreeNode(root_val)
        in_idx = index_map[root_val]
        left_size = in_idx - in_l          # 左子树节点数
        root.left = build(pre_l + 1, pre_l + left_size, in_l, in_idx - 1)
        root.right = build(pre_l + left_size + 1, pre_r, in_idx + 1, in_r)
        return root

    return build(0, len(preorder) - 1, 0, len(inorder) - 1)
```

**复杂度：** O(n) / O(n)（哈希表）。

**易错点：** `left_size = in_idx - in_l` 是切分前序左右区间的关键；前序右子树起点是 `pre_l + left_size + 1`。

**关联题目：**
- [[02-Wiki/题目详解/105-从前序与中序遍历构造二叉树]]
- [[02-Wiki/题目详解/108-将有序数组转换为二叉搜索树]]（数组二分构建，同类递归）

### 模板 11：最大路径和 —— 后序 + 全局最大

**一句话原理：** 每个节点计算"经过它的最大路径" = `node.val + left_gain + right_gain`（左右增益取正）；同时向父节点只返回"单侧最大贡献" = `node.val + max(left_gain, right_gain)`。

**使用场景：** 树中任意路径的最大和（路径可不在根、可不经过根）。

**模板代码：**
```python
def max_path_sum(root):
    best = float('-inf')

    def dfs(node):
        nonlocal best
        if not node:
            return 0
        left = max(dfs(node.left), 0)    # 负贡献直接舍弃
        right = max(dfs(node.right), 0)
        best = max(best, node.val + left + right)  # 经过 node 的完整路径
        return node.val + max(left, right)          # 返回单侧贡献

    dfs(root)
    return best
```

**复杂度：** O(n) / O(h)。

**易错点：** 返回值是"单侧最大贡献"，全局变量记"完整路径和"；负数子路径要截断为 0。

**关联题目：**
- [[02-Wiki/题目详解/124-二叉树中的最大路径和]]
- [[02-Wiki/题目详解/543-二叉树的直径]]（同为后序收集信息）

### 模板 12：路径总和 III —— 前缀和 + DFS

**一句话原理：** 在 DFS 路径上维护"从根到当前节点的前缀和"，用哈希表记录前缀和出现次数；对每个节点，`count += seen[cur - target]`。**回溯时删掉当前前缀和**。

**使用场景：** 统计从任意节点向下满足"和为 target"的路径数（树上前缀和，对应数组中的 560）。

**模板代码：**
```python
from collections import defaultdict

def path_sum(root, target_sum):
    seen = defaultdict(int)
    seen[0] = 1
    count = 0

    def dfs(node, cur):
        nonlocal count
        if not node:
            return
        cur += node.val
        count += seen[cur - target_sum]
        seen[cur] += 1
        dfs(node.left, cur)
        dfs(node.right, cur)
        seen[cur] -= 1          # 回溯：撤销本路径贡献
        if seen[cur] == 0:
            del seen[cur]

    dfs(root, 0)
    return count
```

**复杂度：** O(n) / O(h)。

**易错点：** **树上前缀和必须回溯**（删掉当前前缀和），而数组前缀和不需要回溯——这是与 [[02-Wiki/专题总结/03-数组与矩阵]] 模板 2 的关键区别。

**关联题目：**
- [[02-Wiki/题目详解/437-路径总和III]]
- [[02-Wiki/题目详解/560-和为K的子数组]]（数组版同思路，跨 [[02-Wiki/专题总结/03-数组与矩阵]]）

## 四、模板选择决策（什么时候用哪个）

```
拿到树题：先问"要整棵树的信息还是路径信息？"
├── 按层处理 / 求最短路径层数 → 模板3 BFS
├── 需要子树信息向上汇聚（深度/直径/路径和/LCA）→ 模板4/9/11 后序+分解法
├── 需要在遍历中记录状态（翻转/展开）→ 模板5/1 前序+遍历法
├── BST 相关（有序性）→ 模板7/8 中序
├── 构造/重建 → 模板10 递归切分
└── 从任意节点向下的路径和 → 模板12 前缀和+DFS

第二个问题：递归范式怎么选？
├── 需要返回值给父节点 → 分解法
├── 只需要在遍历时更新全局答案 → 遍历法
└── 树太深怕栈溢出 / 被要求非递归 → 模板2 迭代遍历
```

## 五、易错点清单（专题级全局易错点）

1. **递归返回值 vs 全局变量**：需要子树信息时用返回值（后序），需要路径/全局最优时用全局变量
2. **None 处理**：每个递归函数先 `if not root: return`（或返回对应基线值 0 / None / True）
3. **BST 验证**：用中序有序性，不要只比较当前节点和左右孩子
4. **`nonlocal`**：在嵌套函数里修改外层变量必须声明 `nonlocal`，否则报错或静默失效
5. **路径问题**：437 前缀和必须回溯；124 返回"单侧贡献"、记"完整路径"
6. **BFS 分层**：先 `level_size = len(q)` 再循环，否则混层
7. **构造区间**：`left_size` 是切分前序区间的关键，别用错下标
