## 二、本质理解（专题核心思想）

**数组是连续内存块**：O(1) 随机访问、O(n) 插入/删除。**矩阵是二维数组**（行优先连续存储）。

数组技巧的核心是"下标艺术" **——用下标关系表达元素间的相对位置；矩阵是数组的二维延伸，核心是"边界管理"**。

```
数组（一维下标艺术）
├── 前缀和 / 差分：用历史累积表达区间信息
├── 原地操作：用下标当哈希 / 用翻转代替移动
├── Kadane：滚动状态压缩（最大连续子数组和）
└── 矩阵（二维边界管理）
    ├── 螺旋 / 旋转 / 置零 / 搜索：方向数组 dirs + 边界收缩
```

## 三、核心模板技巧

### 模板 1：前缀和 —— 区间和 O(1) 查询

**一句话原理：** 预处理一个累加数组，把"区间 `[i, j]` 的和"变成"两个前缀和的差"，用空间换时间。

**使用场景：**
- 需要反复查询子数组和（查询次数多时优势明显）
- 与哈希表结合 → "和为 K 的子数组个数"（560）
- 树上前缀和 → 路径和统计（437，跨 [[02-Wiki/专题总结/05-二叉树]]）
- 不适合：只查一次区间和，直接累加即可，前缀和反而多余

**模板代码：**
```python
def build_prefix(nums):
    n = len(nums)
    prefix = [0] * (n + 1)      # prefix[i] = nums[0..i-1] 的和
    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]
    return prefix

def range_sum(prefix, i, j):    # 闭区间 [i, j] 的和
    return prefix[j + 1] - prefix[i]
```

**为什么下标 +1：** `prefix[0] = 0` 表示"空前缀"，统一了 `i = 0` 的情况，`range_sum` 无需特判；也自然支持"从 0 开始"的子数组。

**复杂度：** 预处理 O(n) / 每次查询 O(1) / 空间 O(n)。

**易错点：**
- 忘记 `prefix[0] = 0`，导致 i=0 的区间算错
- `prefix[j+1] - prefix[i]` 的下标别写成 `prefix[j] - prefix[i]`

**关联题目：**
- [[02-Wiki/题目详解/560-和为K的子数组]]（前缀和 + 哈希）
- [[02-Wiki/题目详解/437-路径总和III]]（树上前缀和，跨 [[02-Wiki/专题总结/05-二叉树]]）
- [[02-Wiki/题目详解/238-除自身以外数组的乘积]]（前缀积，同族）

### 模板 2：前缀和 + 哈希表 —— 和为 K 的子数组个数

**一句话原理：** 子数组 `[i, j]` 和为 k ⇔ `prefix[j+1] - prefix[i] = k`，所以遍历时用哈希表记录"之前出现过的前缀和次数"，边遍历边累计。

**使用场景：** 统计"和为 k 的**连续**子数组"个数。**注意：数组含负数时不能用滑动窗口**（窗口伸缩条件失效），必须用前缀和 + 哈希。

**模板代码：**
```python
from collections import defaultdict

def subarray_sum(nums, k):
    count, cur = 0, 0
    seen = defaultdict(int)
    seen[0] = 1                     # 空前缀和 = 0 出现 1 次
    for x in nums:
        cur += x
        count += seen[cur - k]      # 之前出现过多少次前缀和 cur-k
        seen[cur] += 1
    return count
```

**为什么对：** 每个"和为 k 的子数组"唯一对应一对 `(i, j)`，`seen[cur-k]` 恰好统计了能与之配对的 i 的数量，因此累计即答案。

**复杂度：** O(n) / O(n)。

**易错点：**
- 忘初始化 `seen[0] = 1` → 漏掉从 0 开始的子数组
- **顺序不能反**：必须先 `count += seen[cur-k]` 再 `seen[cur] += 1`，否则把当前元素自己也算进去

**关联题目：**
- [[02-Wiki/题目详解/560-和为K的子数组]]
- [[02-Wiki/题目详解/1-两数之和]]（同一"边遍历边查"思路）

### 模板 3：差分 —— 区间批量增减

**一句话原理：** 差分是前缀和的逆运算。只记录每个区间在 `l` 处 `+val`、`r+1` 处 `-val`（"拐点"），最后用一次前缀和把所有变化铺开。

**使用场景：**
- 多次对区间 `[l, r]` 整体加/减同一个值，最后只输出一次结果
- 典型如航班预订、区间覆盖类问题（Hot 100 无直接题，但思想常用）

**模板代码：**
```python
def apply_diff(nums, updates):
    n = len(nums)
    diff = [0] * (n + 1)
    for l, r, val in updates:
        diff[l] += val          # 起点开始 +val
        diff[r + 1] -= val      # 终点之后恢复
    for i in range(n):
        diff[i + 1] += diff[i]  # 前缀和还原
        nums[i] += diff[i]
    return nums
```

**复杂度：** O(n + m)（m 为区间数）/ 空间 O(n)。

**易错点：**
- 还原时累加方向：`diff[i+1] += diff[i]` 必须从左到右
- `r + 1` 不要越界（diff 长度是 n+1 正是为此）

**关联题目：** Hot 100 无直接差分题；掌握思想即可。

### 模板 4：三次翻转 —— 轮转数组

**一句话原理：** 整体翻转 + 两次局部翻转 = 把末尾 k 个元素搬到头部且顺序正确。翻转两次会抵消位置差。

**使用场景：** 数组轮转/循环右移 k 位，要求 O(1) 空间。

**模板代码：**
```python
def rotate(nums, k):
    k %= len(nums)                  # k 可能大于 n
    nums.reverse()                  # 整体翻转
    nums[:k] = reversed(nums[:k])   # 前 k 个翻转
    nums[k:] = reversed(nums[k:])   # 后 n-k 个翻转
```

**复杂度：** O(n) / O(1)。

**易错点：**
- **忘记 `k %= len(nums)`**：k 可能比 n 大
- 切片赋值 `nums[:k] = reversed(...)` 才是原地修改；`nums[:k]` 单独用是新建副本

**关联题目：**
- [[02-Wiki/题目详解/189-轮转数组]]

### 模板 5：前缀积 + 后缀积 —— 除自身以外数组的乘积

**一句话原理：** `answer[i] = 左边所有数的积 × 右边所有数的积`。一趟前缀攒左边，一趟后缀乘右边，不额外开数组。

**使用场景：** 每个位置需要"除自己外全部元素的某种聚合"（积/和/最值），且要求 O(1) 额外空间。

**模板代码：**
```python
def product_except_self(nums):
    n = len(nums)
    res = [1] * n
    pre = 1
    for i in range(n):
        res[i] = pre        # 先填左边积
        pre *= nums[i]
    suf = 1
    for i in range(n - 1, -1, -1):
        res[i] *= suf       # 再乘右边积
        suf *= nums[i]
    return res
```

**复杂度：** O(n) / O(1)（输出数组不计入空间）。

**易错点：**
- 初始化 `res = [1] * n` 而不是 `[0] * n`（否则乘出来全是 0）
- 后缀遍历必须从右往左（`range(n-1, -1, -1)`）

**关联题目：**
- [[02-Wiki/题目详解/238-除自身以外数组的乘积]]

### 模板 6：原地哈希 —— 缺失的第一个正数

**一句话原理：** 把数组本身当哈希表：值 `x` 应放在下标 `x-1` 处。归位后，第一个 `nums[i] != i+1` 的位置 `i+1` 就是答案。

**使用场景：** 找缺失/重复数字，要求 O(1) 空间。**前提：** 数据范围在 `[1, n]` 附近（否则归位无意义）。

**模板代码：**
```python
def first_missing_positive(nums):
    n = len(nums)
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1
```

**复杂度：** O(n)（每个元素最多归位一次）/ O(1)。

**易错点：**
- 交换条件要同时检查"目标位已正确则停"，否则可能死循环
- 只处理 `[1, n]` 范围内的值，越界/非正直接跳过

**关联题目：**
- [[02-Wiki/题目详解/41-缺失的第一个正数]]
- [[02-Wiki/题目详解/287-寻找重复数]]（同思路变体，跨 [[02-Wiki/专题总结/12-技巧专题]]）

### 模板 7：Kadane 算法 —— 最大子数组和

**一句话原理：** `cur = max(num, cur + num)`：当历史累加和为负时，它只会拖累后续，直接放弃、从当前元素重新开始。

**使用场景：** 最大连续子数组和（或乘积，乘积分正负讨论）。注意：这是"**连续**子数组"专属；不连续的子序列问题用 [[02-Wiki/专题总结/10-动态规划]]。

**模板代码：**
```python
def max_sub_array(nums):
    cur = best = nums[0]
    for num in nums[1:]:
        cur = max(num, cur + num)
        best = max(best, cur)
    return best
```

**复杂度：** O(n) / O(1)。

**易错点：**
- `best` 初始化为 `nums[0]` 而不是 0（全负数数组时 0 是错误答案）
- 可对照"前缀和最小"写法理解（`best = max(cur - min_pre)`）

**关联题目：**
- [[02-Wiki/题目详解/53-最大子数组和]]
- [[02-Wiki/题目详解/152-乘积最大子数组]]（Kadane 变体，跨 [[02-Wiki/专题总结/10-动态规划]]）

### 模板 8：合并区间 —— 排序 + 扫描

**一句话原理：** 先按左端点排序，使重叠关系变成"只与上一个比较"；能合并就更新右端点，否则开新区间。

**使用场景：** 区间合并 / 区间交集 / 区间覆盖类问题。跨专题：完整区间贪心见 [[02-Wiki/专题总结/11-贪心算法]]。

**模板代码：**
```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])   # 按左端点排序
    res = []
    for l, r in intervals:
        if not res or l > res[-1][1]:    # 与上一个不重叠 → 新区间
            res.append([l, r])
        else:                            # 重叠 → 合并（更新右端点）
            res[-1][1] = max(res[-1][1], r)
    return res
```

**复杂度：** O(n log n)（排序主导）/ O(n)（输出数组）。

**易错点：**
- **必须按左端点排序**，否则"只与上一个比较"不成立
- 合并只更新右端点取 max，左端点固定为已排序的起点

**关联题目：**
- [[02-Wiki/题目详解/56-合并区间]]

### 模板 9：螺旋遍历 —— 边界收缩

**一句话原理：** 维护 top/bottom/left/right 四条边界，按"右→下→左→上"循环收缩，每走完一边就收缩边界。

**使用场景：** 按螺旋序输出矩阵元素。

**模板代码：**
```python
def spiral_order(matrix):
    if not matrix:
        return []
    res = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for i in range(left, right + 1):   # 右
            res.append(matrix[top][i])
        top += 1
        for i in range(top, bottom + 1):   # 下
            res.append(matrix[i][right])
        right -= 1
        if top <= bottom:
            for i in range(right, left - 1, -1):  # 左
                res.append(matrix[bottom][i])
            bottom -= 1
        if left <= right:
            for i in range(bottom, top - 1, -1):  # 上
                res.append(matrix[i][left])
            left += 1
    return res
```

**复杂度：** O(m×n) / O(1)（不计输出）。

**易错点：**
- 走完"右"和"下"后必须检查 `top <= bottom`、`left <= right`，否则单行/单列会重复
- 空矩阵先判空

**关联题目：**
- [[02-Wiki/题目详解/54-螺旋矩阵]]

### 模板 10：旋转图像 —— 转置 + 翻转

**一句话原理：** 顺时针旋转 90° = 先转置（沿主对角线对称），再每行翻转。

**使用场景：** 原地旋转矩阵（顺时针/逆时针）。

**模板代码：**
```python
def rotate(matrix):
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):       # 只处理上三角
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()
```

**复杂度：** O(n²) / O(1)。

**易错点：**
- 转置内层从 `i+1` 开始，避免每个元素交换两次回到原样
- 逆时针旋转 = 转置 + 每列翻转（对称记忆）

**关联题目：**
- [[02-Wiki/题目详解/48-旋转图像]]

### 模板 11：矩阵置零 —— 第一行/列做标记

**一句话原理：** 用第一行和第一列当"标记板"记录哪些行/列要置零，避免 O(m+n) 额外空间；关键是先记录首行首列自身的原始状态。

**使用场景：** 原地把含 0 的行列全置 0，要求 O(1) 空间。

**模板代码：**
```python
def set_zeroes(matrix):
    m, n = len(matrix), len(matrix[0])
    first_row_zero = any(matrix[0][j] == 0 for j in range(n))
    first_col_zero = any(matrix[i][0] == 0 for i in range(m))
    for i in range(1, m):
        for j in range(1, n):
            if matrix[i][j] == 0:
                matrix[i][0] = 0
                matrix[0][j] = 0
    for i in range(1, m):
        for j in range(1, n):
            if matrix[i][0] == 0 or matrix[0][j] == 0:
                matrix[i][j] = 0
    if first_row_zero:
        for j in range(n):
            matrix[0][j] = 0
    if first_col_zero:
        for i in range(m):
            matrix[i][0] = 0
```

**复杂度：** O(m×n) / O(1)。

**易错点：**
- **必须先记录首行首列是否含 0**，再开始标记，否则标记板会被清零
- 首行/首列在最后单独处理，不能并入标记循环

**关联题目：**
- [[02-Wiki/题目详解/73-矩阵置零]]

### 模板 12：搜索二维矩阵 II —— 右上角出发

**一句话原理：** 从右上角出发，利用"行递增 + 列递增"的单调性：`> target` 左移，`< target` 下移，每次排除一行或一列。

**使用场景：** 行、列都分别递增的矩阵中查找目标（每行每列独立递增）。

**模板代码：**
```python
def search_matrix(matrix, target):
    if not matrix or not matrix[0]:
        return False
    row, col = 0, len(matrix[0]) - 1
    while row < len(matrix) and col >= 0:
        if matrix[row][col] == target:
            return True
        elif matrix[row][col] > target:
            col -= 1
        else:
            row += 1
    return False
```

**复杂度：** O(m + n) / O(1)。

**易错点：**
- 只能从右上角或左下角出发；左上/右下两个方向都单调，无法排除
- 空矩阵/空行判空

**关联题目：**
- [[02-Wiki/题目详解/240-搜索二维矩阵II]]

## 五、易错点清单（专题级全局易错点）

1. **切片是新建**：`nums[:k] = reversed(...)` 才是原地修改；`nums[:k]` 单独用是复制副本
2. **忘记取模**：轮转数组 `k %= len(nums)`，k 可能比 n 大
3. **原地覆盖**：改原数组前问"这个值之后还用不用？"（前缀积 res 先写左再乘右就是为此）
4. **边界 +1/-1**：前缀和 `prefix[j+1] - prefix[i]`；螺旋收缩条件 `top <= bottom and left <= right`
5. **初始化陷阱**：Kadane 的 best 初始化 `nums[0]`（全负数）；前缀积 res 初始化 1
6. **原地哈希死循环**：交换时目标位已正确必须停
7. **差分还原方向**：`diff[i+1] += diff[i]` 从左到右，不能倒序
8. **矩阵置零顺序**：先记录首行首列状态，再标记，最后单独置零
