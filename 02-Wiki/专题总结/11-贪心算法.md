### 1.2 必须理解的本专题约定

- **贪心 = 每一步做当前最优选择**，期望全局最优。适用范围：满足"贪心选择性质 + 最优子结构"
- **反例验证法**：想不到反例，贪心策略大概率对（代码随想录）
- **贪心 vs DP**：贪心更快但需要证明；DP 通用但更重。遇到"局部最优似乎成立但不确定" → 先找反例，找不到再放心贪心
- **排序预处理**：区间类贪心（合并/无重叠）几乎都要先排序

## 二、本质理解（专题核心思想）

labuladong 将贪心定位为"穷举 + 剪枝"的一种特殊形式——每一步选当前看起来最优的方案。

| 对比 | 贪心算法 | 动态规划 |
|------|----------|----------|
| 决策方式 | 只考虑局部最优 | 考虑所有可能 |
| 适用范围 | 满足贪心选择性质 | 更通用 |
| 效率 | O(n) 或 O(n log n) | 通常 O(n²) |
| 难度 | 难在证明"贪心是对的" | 难在找状态转移 |

**核心流程：** 大胆假设贪心策略 → 找反例验证 → 找不到反例就实现 → 证明/复盘为什么对。

## 三、核心模板技巧

### 模板 1：买卖股票 —— 维护历史最低价

**一句话原理：** 遍历时维护"当前见过的最低买入价"，每天尝试"今天卖"并更新最大利润。因为最优买点必然是某天的历史最低点。

**使用场景：** 一次买卖股票类问题（只能交易一次）。

**模板代码：**
```python
def max_profit(prices):
    min_price = float('inf')
    max_profit = 0
    for price in prices:
        min_price = min(min_price, price)         # 更新历史最低价
        max_profit = max(max_profit, price - min_price)  # 今天卖能赚多少
    return max_profit
```

**为什么对：** 第 i 天卖出能获得的最大利润只取决于第 i 天之前的最低价格，遍历一遍即可覆盖所有"卖出日"。

**复杂度：** O(n) / O(1)。

**易错点：** 先更新 `min_price` 再算 `price - min_price`（保证卖在买之后）。

**关联题目：**
- [[02-Wiki/题目详解/121-买卖股票的最佳时机]]

### 模板 2：跳跃游戏 —— 维护最远可达位置

**一句话原理：** 遍历中实时更新"从已访问位置能跳到的最远下标" `max_reach`；只要当前位置可达（`i <= max_reach`）且 `max_reach` 能覆盖终点即可。

**使用场景：** 判断能否到达终点（不要求最小步数）。

**模板代码：**
```python
def can_jump(nums):
    max_reach = 0
    for i in range(len(nums)):
        if i > max_reach:                # 当前位置不可达
            return False
        max_reach = max(max_reach, i + nums[i])
        if max_reach >= len(nums) - 1:
            return True
    return True
```

**为什么对：** 可达范围是连续的 `[0, max_reach]`——因为每个可达位置都能继续向后跳，所以"最远可达"单调覆盖，不漏解。

**复杂度：** O(n) / O(1)。

**易错点：** 先判断 `i > max_reach`（不可达）再更新；用 `max_reach >= len(nums)-1` 提前返回。

**关联题目：**
- [[02-Wiki/题目详解/55-跳跃游戏]]

### 模板 3：跳跃游戏 II —— 最少步数

**一句话原理：** BFS 式贪心：维护"当前步数的右边界 `end`"和"下一步能达到的最远 `max_reach`"；遍历到 `end` 时步数 +1。

**使用场景：** 求到达终点的**最少**跳跃次数。

**模板代码：**
```python
def jump(nums):
    n = len(nums)
    jumps = 0
    cur_end = 0          # 当前步数能到的右边界
    max_reach = 0        # 已访问位置能到的最远
    for i in range(n - 1):
        max_reach = max(max_reach, i + nums[i])
        if i == cur_end:        # 走到当前步数边界，必须再跳一次
            jumps += 1
            cur_end = max_reach
            if cur_end >= n - 1:
                break
    return jumps
```

**为什么对：** 在"本步能覆盖的区间"内找出下一步最远，走完本区间即多跳一步——等价于 BFS 分层求最短步数。

**复杂度：** O(n) / O(1)。

**易错点：** 循环到 `n-2` 即可（终点不需要跳）；`cur_end` 更新用 `max_reach`。

**关联题目：**
- [[02-Wiki/题目详解/45-跳跃游戏II]]

### 模板 4：划分字母区间 —— 记录字符末位置

**一句话原理：** 先记录每个字符**最后出现的位置**；遍历时维护当前段的 `end = max(end, last[ch])`，到达 `end` 即一个合法分段。

**使用场景：** 把字符串分成尽量多段，使每个字符只出现在一段中。

**模板代码：**
```python
def partition_labels(s):
    last_pos = {ch: i for i, ch in enumerate(s)}   # 每个字符最后出现位置
    res = []
    start = end = 0
    for i, ch in enumerate(s):
        end = max(end, last_pos[ch])       # 当前段必须覆盖到该字符的最后位置
        if i == end:                       # 到达段边界
            res.append(end - start + 1)
            start = i + 1
    return res
```

**为什么对：** 某字符最后出现在 end，则它所在段至少要到 end；贪心地在每个 end 处截断就能得到最多段。

**复杂度：** O(n) / O(1)（字符集固定）。

**易错点：** `end` 实时取 max；段边界判断是 `i == end`。

**关联题目：**
- [[02-Wiki/题目详解/763-划分字母区间]]

### 模板 5：区间贪心 —— 排序 + 扫描

**一句话原理：** 先按左端点（或右端点）排序，把"任意区间重叠"化简为"只与上一个区间比较"，再按需合并/计数。

**使用场景：** 合并区间、无重叠区间、用最少数箭引爆气球等区间类题。

**模板代码（合并区间）：**
```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])    # 按左端点排序
    res = []
    for l, r in intervals:
        if not res or l > res[-1][1]:     # 与上一个不重叠
            res.append([l, r])
        else:                             # 重叠 → 合并（更新右端点）
            res[-1][1] = max(res[-1][1], r)
    return res
```

**变体：** 求"移除最小区间使剩余无重叠" → 按右端点排序，尽量保留结束早的区间。

**复杂度：** O(n log n) / O(n)。

**易错点：** 合并题按左端点排序；"无重叠"题按右端点排序（结束越早越优）。

**关联题目：**
- [[02-Wiki/题目详解/56-合并区间]]（跨 [[02-Wiki/专题总结/03-数组与矩阵]]）

## 四、模板选择决策（什么时候用哪个）

```
贪心题先问：能不能维护一个"历史最值/可达范围"？
├── 只能交易一次求最大利润 → 模板1 维护历史最低价
├── 判断能否到达终点 → 模板2 维护最远可达
├── 求最少步数到终点 → 模板3 BFS 式贪心（end + max_reach）
├── 分段且每字符只在一段 → 模板4 记录末位置
└── 区间关系题 → 模板5 排序 + 扫描

拿不准是不是贪心：
├── 先找反例 → 找不到就用贪心
└── 找到反例 → 换 DP（[[02-Wiki/专题总结/10-动态规划]]）
```

## 五、易错点清单（专题级全局易错点）

1. **贪心不是万能**：遇到反例立即换 DP，不要硬套
2. **排序预处理**：区间类题先排序；按哪个端点排序要按题目意图选
3. **局部最优 ≠ 全局最优**：每一步"看起来好"不代表全局好，必须验证单调性
4. **边界维护**：跳跃游戏的 `max_reach`、区间题的 `end`，更新时机要正确
5. **先更新还是先用**：买卖股票必须先更新 `min_price` 再用
