### 1.2 必须理解的本专题约定

- **统一用左闭右开区间 `[left, right)`**：窗口长度 = `right - left`，空窗口时 `left == right`，避免 `+1/-1` 混乱
- **labuladong 双指针分类**：左右指针（对撞）/ 快慢指针（同向）/ 滑动窗口（同向维护区间）
- **滑动窗口三问法**：什么时候扩？什么时候缩？什么时候更新答案？
  - 求最长 → 窗口合法后更新答案
  - 求最短 → 窗口合法时、左缩前更新答案
- **"不变量"思维**：每次移动指针，要能说明"为什么不会漏掉答案"

## 二、本质理解（专题核心思想）

双指针的核心思想是**利用两个指针的相对运动来减少搜索空间**。

```
双指针
├── 左右指针（对撞）：两端向中间移动 → 有序数组、回文串
├── 快慢指针（同向）：一快一慢 → 链表判环、找中点、数组原地整理
└── 滑动窗口（同向）：维护一个连续区间 → 子串/子数组问题
```

**延伸理解：** 滑动窗口本质上是**快慢指针的一种特殊形式**——窗口内的元素始终连续。

**用"不变量"理解双指针：** 做题前先明确四件事——① 指针的含义；② 当前区间的定义（统一 `[left, right)`）；③ 移动条件；④ 移动后仍然成立的性质（不变量）。没有不变量，双指针只是"凭感觉移动"。

## 三、核心模板技巧

### 模板 1：对撞指针 —— 两数之和（有序）

**一句话原理：** 有序数组中，两指针从两端向中间：和太小右移左指针，和太大左移右指针。移动的依据是"单调性保证移动后不会漏解"。

**使用场景：** 有序数组找两数满足关系、回文判断。

**模板代码：**
```python
def two_sum_sorted(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            return [left, right]
        elif s < target:
            left += 1       # 和太小，只能增大 left
        else:
            right -= 1      # 和太大，只能减小 right
    return []
```

**为什么移动较短侧不漏解：** 以盛水容器为例——`min(height[l], height[r]) * (r-l)`；若左边更短，移动右指针宽度必变小、高度仍被左短板限制，不可能更优，所以只能移动较短一侧。

**复杂度：** O(n) / O(1)。

**易错点：** 前提是**有序**；未排序先用 `sort`。

**关联题目：**
- [[02-Wiki/题目详解/11-盛最多水的容器]]
- [[02-Wiki/题目详解/283-移动零]]（快慢对撞结合）

### 模板 2：对撞指针 —— 三数之和

**一句话原理：** 固定一个数，剩下的用对撞指针找两数之和；**排序带来的三个好处**：双指针 O(n) 找和、相邻重复去重、`nums[i] > 0` 剪枝。

**使用场景：** 三数之和/四数之和（排序 + 对撞 + 去重）。

**模板代码：**
```python
def three_sum(nums):
    nums.sort()
    n = len(nums)
    res = []
    for i in range(n - 2):
        if nums[i] > 0:                    # 剪枝
            break
        if i > 0 and nums[i] == nums[i - 1]:   # 外层去重
            continue
        left, right = i + 1, n - 1
        while left < right:
            s = nums[i] + nums[left] + nums[right]
            if s == 0:
                res.append([nums[i], nums[left], nums[right]])
                left += 1
                right -= 1
                while left < right and nums[left] == nums[left - 1]:   # 内层去重
                    left += 1
                while left < right and nums[right] == nums[right + 1]: # 内层去重
                    right -= 1
            elif s < 0:
                left += 1
            else:
                right -= 1
    return res
```

**复杂度：** O(n²) / O(1)（不计输出）。

**易错点：** 三层去重（固定位 + 左右指针）都不能漏；剪枝 `nums[i] > 0` 依赖排序。

**关联题目：**
- [[02-Wiki/题目详解/15-三数之和]]
- [[02-Wiki/题目详解/42-接雨水]]（对撞维护左右最高）

### 模板 3：快慢指针 —— 链表判环 / 找中点

**一句话原理：** 快指针走 2 步、慢指针走 1 步：判环（相遇则有环）、找中点（快到尾慢在中点）、找环入口（Floyd 两阶段）。

**使用场景：** 链表判环、找环入口、找中点；数组原地整理（slow 写有效元素）。

**模板代码：**
```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False

def middle_node(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow

def detect_cycle(head):              # Floyd 找环入口
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            break
    else:
        return None
    slow = head
    while slow != fast:
        slow = slow.next
        fast = fast.next
    return slow
```

**复杂度：** O(n) / O(1)。

**易错点：** 循环条件必须同时判 `fast and fast.next`，否则 `fast.next.next` 空指针；`while...else` 的 else 在无环时执行。

**关联题目：**
- [[02-Wiki/题目详解/141-环形链表]]、[[02-Wiki/题目详解/142-环形链表II]]（跨 [[02-Wiki/专题总结/04-链表]]）
- [[02-Wiki/题目详解/283-移动零]]（数组快慢指针原地整理）

### 模板 4：滑动窗口通用框架

**一句话原理：** 右指针扩窗 → 不满足条件时左指针缩窗 → 更新答案。三问法决定扩缩与更新时机。

**使用场景：** 连续子串/子数组问题。

**模板代码：**
```python
from collections import defaultdict

def sliding_window(s):
    left, right = 0, 0
    window = defaultdict(int)      # 窗口内元素统计
    # need = ...                   # 目标条件（看题目）

    while right < len(s):
        # 扩大窗口
        c = s[right]
        right += 1
        window[c] += 1
        # ... 更新窗口数据 ...

        # 缩小窗口（当窗口需要缩小时）
        while "窗口需要缩小":
            d = s[left]
            left += 1
            window[d] -= 1
            if window[d] == 0:
                del window[d]
            # ... 更新窗口数据 ...

    return result
```

**复杂度：** O(n)（left/right 各移动最多 n 次，总 2n）/ O(k)。

**易错点：** 求最长在"扩后合法"更新；求最短在"缩前合法"更新；移出与加入的计数必须对称。

**关联题目：** 以下三个应用的基础框架。

### 模板 5：滑动窗口·求最长 —— 无重复字符的最长子串

**一句话原理：** 右扩字符并计数，窗口出现重复（`window[c] > 1`）时左缩直到无重复；每次窗口合法后 `right - left` 更新最长。

**使用场景：** 求最长连续子串满足某约束。

**模板代码：**
```python
def length_of_longest_substring(s):
    window = defaultdict(int)
    left = right = 0
    max_len = 0
    while right < len(s):
        c = s[right]
        right += 1
        window[c] += 1
        while window[c] > 1:          # 有重复 → 左缩
            d = s[left]
            left += 1
            window[d] -= 1
        max_len = max(max_len, right - left)   # 合法后更新（求最长）
    return max_len
```

**复杂度：** O(n) / O(k)（k 为字符集大小）。

**易错点：** 右边界对应 `right-1`（已右移后的 right 是开区间边界）；左缩用 `while` 直到无重复。

**关联题目：**
- [[02-Wiki/题目详解/3-无重复字符的最长子串]]

### 模板 6：滑动窗口·求最短 —— 最小覆盖子串（valid）

**一句话原理：** `need` 统计目标需求、`window` 统计窗口、`valid` 记录**已满足需求的字符种类数**；`valid == len(need)` 即全覆盖，此时左缩找最短，每次缩前更新答案。

**使用场景：** 求最短子串覆盖目标字符集（"不定长 + 多条件满足"）。

**模板代码：**
```python
def min_window(s, t):
    need = defaultdict(int)
    window = defaultdict(int)
    for c in t:
        need[c] += 1

    left = 0
    valid = 0
    start, length = 0, float('inf')

    for right, ch in enumerate(s):
        if ch in need:
            window[ch] += 1
            if window[ch] == need[ch]:
                valid += 1

        while valid == len(need):          # 全覆盖 → 左缩
            if right - left + 1 < length:  # 缩前更新（求最短）
                start, length = left, right - left + 1
            d = s[left]
            left += 1
            if d in need:
                if window[d] == need[d]:
                    valid -= 1
                window[d] -= 1

    return s[start:start + length] if length != float('inf') else ""
```

**为什么 valid 是"种类数"：** `valid` 表示满足需求的**字符种类数**，不是字符总数；移出字符时 `valid -= 1` 必须在 `window[d] -= 1` **之前**（先判断"刚好从满足变不满足"的时刻）。

**复杂度：** O(n) / O(k)。

**易错点：** `valid` 加减顺序；缩前更新答案；`length` 初始化 `float('inf')`。

**关联题目：**
- [[02-Wiki/题目详解/76-最小覆盖子串]]

### 模板 7：定长滑动窗口 —— 找到字符串中所有字母异位词

**一句话原理：** 窗口长度固定为 `len(p)`，每次只处理"新进入 + 离开"的字符（复用上一个窗口的结果），窗口与 `p` 计数相等即一个起始位置。

**使用场景：** 定长窗口 + 频次比较。

**模板代码：**
```python
from collections import Counter

def find_anagrams(s, p):
    need = Counter(p)
    window = Counter()
    left = 0
    result = []
    for right, ch in enumerate(s):
        window[ch] += 1
        if right - left + 1 > len(p):      # 超长 → 移出最左
            old = s[left]
            window[old] -= 1
            if window[old] == 0:
                del window[old]
            left += 1
        if right - left + 1 == len(p):     # 定长时比较
            if window == need:
                result.append(left)
    return result
```

**复杂度：** O(n) / O(1)（字符集固定）。

**易错点：** 定长窗口先移出再比较；用 `Counter` 相等比较。

**关联题目：**
- [[02-Wiki/题目详解/438-找到字符串中所有字母异位词]]

### 模板 8：单调队列 —— 滑动窗口最大值

**一句话原理：** `deque` 存索引、值单调递减；新元素弹出队尾所有比它小的（它们再也没机会当最大），再弹过期索引，队首即最大值。

**使用场景：** 固定窗口滑动取最值（跨 [[02-Wiki/专题总结/06-栈与堆]] 模板 7）。

**模板代码：**
```python
from collections import deque

def max_sliding_window(nums, k):
    q = deque()          # 存索引，单调递减
    res = []
    for i, num in enumerate(nums):
        while q and nums[q[-1]] < num:
            q.pop()
        q.append(i)
        if q[0] <= i - k:
            q.popleft()
        if i >= k - 1:
            res.append(nums[q[0]])
    return res
```

**复杂度：** O(n) / O(k)。

**易错点：** 队列存索引；维护单调 → 入队 → 过期 → 记录的顺序不能乱。

**关联题目：**
- [[02-Wiki/题目详解/239-滑动窗口最大值]]

## 四、模板选择决策（什么时候用哪个）

```
题目是否要求连续子数组/子串？
├── 是 → 滑动窗口
│   ├── 求最长（约束下尽量长）→ 模板5（合法后更新）
│   ├── 求最短（覆盖目标）→ 模板6（缩前更新 + valid）
│   ├── 窗口长度固定 → 模板7（定长 + 频次比较）
│   └── 窗口内取最值 → 模板8 单调队列
└── 否
    ├── 数据有序/回文/两数关系 → 模板1/2 对撞指针
    ├── 链表判环/中点/原地整理 → 模板3 快慢指针
    └── 以上都不是 → 哈希/排序/二分/DP
```

## 五、易错点清单（专题级全局易错点）

1. **区间约定统一**：`[left, right)` 时长度是 `right - left`；闭区间才是 `right - left + 1`
2. **更新答案时机**：求最长在窗口合法后更新；求最短在窗口合法时、左缩前更新
3. **窗口计数对称**：加入与移出必须更新同一组状态；`valid` 增减与 `window` 增减顺序不能颠倒
4. **对撞前提有序**：未排序先用 `sort`；移动较短侧要有"不会漏解"的理由
5. **快慢指针判环**：循环条件 `fast and fast.next`，防止空指针
6. **切片是新建**：`s[left:right]` 每次复制 O(k)，别在循环里反复切片导致退化
