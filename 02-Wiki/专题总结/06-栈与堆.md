## 一、前备知识（开始本专题前必须会什么）

### 1.1 Python 语法最小示例

| 知识点 | 最小示例 | 本专题用途 | 自检问题 |
|--------|----------|-----------|----------|
| list 当栈 | `stack = []; stack.append(x); x = stack.pop()` | 栈的通用实现 | `pop()` 与 `pop(0)` 谁快？ |
| 双向队列 | `from collections import deque; d = deque(); d.append(x); d.popleft()` | 队列/单调队列 | deque 和 list 谁适合做队列？ |
| 堆操作 | `import heapq; heapq.heappush(h, x); heapq.heappop(h)` | 最小堆 | heapq 默认是最大堆还是最小堆？ |
| 大根堆 | `heappush(h, -x); -heappop(h)` | 模拟大根堆 | 为什么存负值？ |

### 1.2 必须理解的本专题约定

- **栈 = LIFO**（后进先出），Python 用 list 的 `append / pop()` 实现；**队列 = FIFO**，用 `deque` 实现
- **单调栈统一存索引**而非值——很多题需要索引算距离/宽度
- **堆 = 优先队列**：Python 只有最小堆 `heapq`，大根堆一律存负值
- **Top K 反直觉**：求第 K **大**，用**最小**堆维护大小为 K 的窗口

## 二、本质理解（专题核心思想）

- **栈（Stack）：** 受限的线性表，LIFO，底层是数组或链表 → 处理"嵌套/回溯/最近匹配"
- **队列（Queue）：** FIFO，配合 `deque` → 处理"顺序/分层"
- **堆（Heap / 优先队列）：** 用数组实现的完全二叉树，自动维护最值 → 处理"动态最值/Top K"
- **单调栈：** 栈内元素单调递增/递减 → 处理"下一个更大/更小元素"

```
栈 → 解决"最近相关性"（括号、嵌套、单调栈）
堆 → 解决"动态最值"（Top K、中位数、贪心取最值）
队列 → 解决"顺序扩散"（BFS、单调队列求滑窗最值）
```

## 三、核心模板技巧

### 模板 1：栈 + 辅助栈 —— 括号匹配 / 最小栈

**一句话原理：** 主栈存数据，辅助栈同步存"当前最值/状态"，保证 O(1) 查询。

**使用场景：** 括号匹配（左入右出）、最小栈（辅助栈存当前最小值）、字符串解码（数字栈 + 字符串栈）。

**模板代码（最小栈）：**
```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []          # 辅助栈，栈顶永远是当前最小值

    def push(self, val):
        self.stack.append(val)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)
        else:
            self.min_stack.append(self.min_stack[-1])  # 同步压入当前最小值

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def get_min(self):
        return self.min_stack[-1]
```

**复杂度：** 所有操作 O(1) / 空间 O(n)。

**易错点：** 辅助栈与主栈同步压入/弹出，长度保持一致。

- [[02-Wiki/题目详解/20-有效的括号]]
- [[02-Wiki/题目详解/155-最小栈]]
- [[02-Wiki/题目详解/394-字符串解码]]

### 模板 2：单调栈 —— 下一个更大元素

**一句话原理：** 维护一个单调递减栈（栈底到栈顶递减）。当前元素比栈顶大时，栈顶的"下一个更大元素"就是当前元素——被弹出即"出结果"。

**使用场景：** "下一个/上一个更大/更小元素"，典型如每日温度。

**模板代码（下一个更大元素）：**
```python
def next_greater_element(nums):
    n = len(nums)
    res = [-1] * n
    stack = []                    # 存索引，单调递减
    for i in range(n):
        while stack and nums[stack[-1]] < nums[i]:
            idx = stack.pop()     # 栈顶的答案就是当前元素
            res[idx] = nums[i]
        stack.append(i)
    return res
```

**四种变体统一：**
| 目标 | 栈的单调性 | 遍历方向 |
|------|-----------|----------|
| 下一个更大元素 | 递减栈 | 从左到右 |
| 下一个更小元素 | 递增栈 | 从左到右 |
| 上一个更大元素 | 递减栈 | 从右到左 |
| 上一个更小元素 | 递增栈 | 从右到左 |

**复杂度：** O(n)（每个元素入栈/出栈一次）/ O(n)。

**易错点：** 存索引而非值；出栈时机是"当前元素大于栈顶"；比较用 `<`（严格）注意相等元素处理。

**关联题目：**
- [[02-Wiki/题目详解/739-每日温度]]

### 模板 3：单调栈经典 —— 柱状图中最大矩形

**一句话原理：** 对每个柱子，找"左右第一个比它矮的柱子"，高度 × 宽度即以其为高的最大矩形。单调递增栈 + 左右哨兵简化边界。

**使用场景：** 最大矩形/接雨水等"以每个元素为最值扩展区间"的题。

**模板代码：**
```python
def largest_rectangle_area(heights):
    stack = []                          # 存索引，递增栈
    heights = [0] + heights + [0]       # 左右加哨兵 0，避免空栈与最后清栈
    max_area = 0
    for i in range(len(heights)):
        while stack and heights[stack[-1]] > heights[i]:
            h = heights[stack.pop()]
            w = i - stack[-1] - 1       # 左右边界：i 是右边第一个更矮，stack[-1] 是左边第一个更矮
            max_area = max(max_area, h * w)
        stack.append(i)
    return max_area
```

**复杂度：** O(n) / O(n)。

**易错点：** 哨兵 0 的作用（避免空栈、强制清空）；宽度 `i - stack[-1] - 1` 的边界。

**关联题目：**
- [[02-Wiki/题目详解/84-柱状图中最大的矩形]]

### 模板 4：堆（heapq）基础

**一句话原理：** `heapq` 是最小堆；大根堆存负值；`heapify` O(n) 建堆；push/pop O(log n)。

**使用场景：** 动态最值、Top K、贪心每次取最大/最小、合并 K 个有序序列。

**模板代码：**
```python
import heapq

heap = []
heapq.heappush(heap, val)        # 入堆
min_val = heapq.heappop(heap)    # 弹出最小值
top = heap[0]                    # 查看最小（不弹出）
heapq.heapify(arr)               # O(n) 原地建堆

# 大根堆（存负值）
heapq.heappush(heap, -val)
max_val = -heapq.heappop(heap)
```

**复杂度：** push/pop O(log n) / 建堆 O(n)。

**易错点：** 大根堆存负值后取回要取负；元组入堆时按第一元素比较（如 `(-count, val)`）。

**关联题目：**
- [[02-Wiki/题目详解/215-数组中的第K个最大元素]]
- [[02-Wiki/题目详解/347-前K个高频元素]]

### 模板 5：Top K / 第 K 大 —— 最小堆维护窗口

**一句话原理：** 用**最小堆**维护当前最大的 K 个元素，堆顶就是第 K 大；比堆顶大才入堆。反直觉但正确：堆只保留最大的 K 个。

**使用场景：** 第 K 大/小、前 K 高频。

**模板代码：**
```python
def top_k_largest(nums, k):
    heap = []
    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:
            heapq.heappop(heap)     # 弹出当前最小，堆里永远是最大的 K 个
    return heap[0]                  # 第 K 大

def top_k_frequent(nums, k):
    from collections import Counter
    counter = Counter(nums)
    return heapq.nlargest(k, counter.keys(), key=counter.get)
```

**复杂度：** O(n log k) / O(k)。

**易错点：** 求第 K 大用最小堆（不是最大堆）；求前 K 高频用 `(-count, val)` 入堆。

**关联题目：**
- [[02-Wiki/题目详解/215-数组中的第K个最大元素]]
- [[02-Wiki/题目详解/347-前K个高频元素]]

### 模板 6：双堆 —— 数据流中位数

**一句话原理：** 大根堆存较小一半、小根堆存较大一半，两堆大小差 ≤ 1，中位数 = 两堆顶之一或均值。

**使用场景：** 动态中位数、滑动窗口中的中位数。

**模板代码：**
```python
class MedianFinder:
    def __init__(self):
        self.small = []   # 大根堆（存负值）→ 较小一半
        self.large = []   # 小根堆 → 较大一半

    def add_num(self, num):
        heapq.heappush(self.small, -num)
        # 保证 small 中所有元素 <= large 中所有元素
        if self.small and self.large and -self.small[0] > self.large[0]:
            heapq.heappush(self.large, -heapq.heappop(self.small))
        # 平衡大小
        if len(self.small) > len(self.large) + 1:
            heapq.heappush(self.large, -heapq.heappop(self.small))
        if len(self.large) > len(self.small):
            heapq.heappush(self.small, -heapq.heappop(self.large))

    def find_median(self):
        if len(self.small) > len(self.large):
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2.0
```

**复杂度：** add O(log n) / find O(1) / 空间 O(n)。

**易错点：** `small` 存负值，比较与取值都要取负；平衡规则要保证"small 比 large 至多多 1"。

**关联题目：**
- [[02-Wiki/题目详解/295-数据流的中位数]]

### 模板 7：队列 / 单调队列 —— 滑动窗口最大值

**一句话原理：** `deque` 实现单调递减队列，队首永远当前窗口最大值；新元素从队尾弹出所有比它小的旧元素（它们再也没机会当最大）。

**使用场景：** 固定窗口滑动的最大值/最小值（关联 [[02-Wiki/专题总结/02-双指针与滑动窗口]] 的滑动窗口）。

**模板代码：**
```python
from collections import deque

def max_sliding_window(nums, k):
    q = deque()          # 存索引，单调递减
    res = []
    for i, num in enumerate(nums):
        while q and nums[q[-1]] < num:   # 弹出队尾比当前小的
            q.pop()
        q.append(i)
        if q[0] <= i - k:                # 弹出过期索引
            q.popleft()
        if i >= k - 1:                   # 窗口形成后记录
            res.append(nums[q[0]])
    return res
```

**复杂度：** O(n) / O(k)。

**易错点：** 队列存索引；维护单调性、入队、过期三个顺序不能乱。

**关联题目：**
- [[02-Wiki/题目详解/239-滑动窗口最大值]]

## 四、模板选择决策（什么时候用哪个）

```
题目特征 → 数据结构
├── 括号/嵌套/最近匹配 → 模板1 栈
├── 需要 O(1) 查询当前最值 → 模板1 辅助栈
├── "下一个更大/更小元素" → 模板2 单调栈
├── 以每个元素为最值扩展区间 → 模板3 单调栈 + 哨兵
├── 动态最值 / Top K / 第 K 大 → 模板4/5 堆
├── 动态中位数 → 模板6 双堆
├── 固定窗口滑动取最值 → 模板7 单调队列
└── 需要同时取最大最小 → 双堆 / 两个堆
```

## 五、易错点清单（专题级全局易错点）

1. **Python 没有大根堆**：存负值模拟，取回时取负
2. **单调栈存索引而非值**：很多题需要索引计算距离/宽度
3. **柱状图加哨兵 0**：避免空栈判断和最后清空栈
4. **Top K 反直觉**：求第 K 大用**最小堆**（堆大小 = K）
5. **堆的复杂度**：push/pop O(log k)，建堆 O(n)
6. **deque vs list**：队列用 `deque`，`list.pop(0)` 是 O(n)
7. **单调队列顺序**：维护单调性 → 入队 → 删除过期 → 记录，顺序别乱
